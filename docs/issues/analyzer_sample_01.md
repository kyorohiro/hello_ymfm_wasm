# VGM Analyzer: サンプルデータの抽出と使用状況表示

## 目的

VGM Analyzerで、PCM / ADPCMを「音が鳴っている」だけで終わらせず、
どのサンプルデータが、どの時刻に、どのチャンネルで、どのような設定で使われているかを確認できるようにする。

例えば、次のような情報を追跡できる状態を目指す。

```text
Sample 03
  種別: YM2610 ADPCM-A
  データ範囲: 0x12000〜0x16fff
  サイズ: 20,480 bytes
  使用時刻: 00:01.240〜00:01.580
  使用チャンネル: ADPCM-A CH2
  再生レート: chip設定値
```

これにより、「この音が、曲中でどのように使われているか」をサンプル単位で確認できるようにする。

## 対象音源

- YM2610 / YM2610B ADPCM-A
- YM2610 / YM2610B ADPCM-B
- YM2608 ADPCM-A / ADPCM-B
- Mega-CD / Sega CD の RF5C164 PCM

FM、SSG、PSGのノート解析とは分ける。ADPCM / PCMは、サンプル番号やメモリアドレスを中心に扱い、
音名への変換は補助情報とする。

## 抽出する情報

### サンプルデータ

- チップ種別
- サンプルID
- VGM内のデータブロック種別
- ROM / RAM上の開始アドレス
- 終了アドレスまたはサイズ
- 元データのバイト列
- データがVGM内に含まれているか
- 圧縮・未対応ブロックの有無

### 再生イベント

- 発音開始時刻・停止時刻
- 使用チャンネル
- サンプルIDまたは再生アドレス
- 再生開始・終了アドレス
- デルタN / 再生周波数などのレート設定
- 音量、パン、ループ設定
- 同じサンプルを使用した回数

サンプル本体がVGMに含まれていない場合は、アドレスや使用時刻だけを表示し、
「ROMデータ未収録」と明示する。

## 実装段階

### 1. データブロックの抽出

VGMのデータブロックから、YM2610 / YM2608 ADPCMとRF5C164のサンプル領域を抽出する。
同じブロックがループで再度現れても、サンプルを重複登録しない。

抽出結果は、次のような内部形式で保持する。

```js
{
  id: 3,
  chip: "ym2610",
  kind: "adpcm-a",
  address: 0x12000,
  size: 0x5000,
  data: Uint8Array,
  embedded: true
}
```

### 2. 再生イベントとの関連付け

レジスタ書き込みを追跡し、データブロックのアドレス範囲と再生設定を関連付ける。
同じサンプルを異なるレートや開始位置で使う場合は、サンプル本体と再生イベントを分けて保持する。

```js
{
  sampleId: 3,
  chip: "ym2610",
  channel: 2,
  start: 54684,
  end: 70560,
  startAddress: 0x12000,
  endAddress: 0x16fff,
  rate: 1234,
  volume: 31,
  loop: false
}
```

### 3. WAV化

既存のYM2610 / YM2608 / RF5C164音源コアを使い、抽出したデータを個別にデコードしてWAVとして保存する。
WAV化できない場合でも、元データのバイナリ抽出とメタデータ表示は可能にする。

### 4. Analyzer表示

`Sample Explorer` 相当の表示を追加する。

- サンプル一覧
- 種別、サイズ、アドレス、収録状態
- 波形プレビュー
- サンプル単体再生
- 曲中の使用回数と使用時刻
- 使用箇所からタイムラインへ移動
- チャンネル単位のミュート

Note-ish上では、音名の代わりに次のような帯を表示する。

```text
ADPCM-A CH2 / Sample 03
RF5C164 PCM CH4 / Sample 12
```

音程がレジスタから推定できる場合だけ、音名を補助表示する。

## 出力との関係

- MIDIでは、サンプル番号と使用時刻をテキストメタデータへ記録する
- MMLでは、FM / SSGの音符とPCM / ADPCMのサンプルイベントを別セクションにする
- WAV出力では、サンプルごとの個別ファイルと、曲中の使用順に並べた試聴用ファイルを作る
- サンプル本体がないイベントは、変換せず警告として残す

音名へ無理に変換せず、サンプルID・アドレス・再生設定を一次情報として保持する。

## 注意点

- YM2610 ADPCM-A、ADPCM-B、YM2608 ADPCM-B、RF5C164 PCMはデータ形式とレジスタ構成が異なる
- VGMにサンプルROMが含まれないファイルがある
- 同じサンプルを異なる再生レート、音量、開始位置、ループ設定で使う場合がある
- ADPCMの発音終了は、単純なKEY OFFや再生開始イベントだけでは決まらない場合がある
- 圧縮データブロック、未対応のVGMコマンド、2台目のチップは個別に警告する
- 既存のMAME移植コアや音源コアの再生結果を、実機の完全一致とは扱わない

## 最初の受け入れ条件

- VGM内のサンプルデータを一覧表示できる
- サンプルの開始アドレスとサイズを表示できる
- 曲中の使用時刻とチャンネルを表示できる
- サンプル本体があれば個別に試聴できる
- サンプル本体がなければ、未収録として明示できる
- ループによる重複登録が発生しない
- 既存のFM / SSG / PSG再生とミュート操作に影響しない

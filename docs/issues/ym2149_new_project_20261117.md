# YM2149 New Project — 2026-11-17

User requested removal of the redundant Examples button and a New Project menu
action. Automatic example files remain; the toolbar no longer has Examples.

## Workflow

**Menu → New Project…** opens a confirmation outside the potentially hidden
Files panel. Before creation starts, Cancel or Escape keeps the workspace and
performance unchanged. The initial focus is Cancel. Musical key input inside
the dialog is blocked by its explicit dialog role and the existing Synth guard.

- **Export current & create** builds the current Cassette, including flushed
  editor text and actual sound settings, and initiates its download before
  retiring the workspace. Browser download initiation is not proof that a user
  completed a filesystem save.
- **Create without export** creates the new workspace directly after that
  explicit choice.

The fresh project contains the existing starter `index.js`, default ST Square
sound and the two readable example files. Selection is `/index.js`, input mode
is Keyboard, physical channel selection is Auto, and Pitch / Octave are zero.
Old project files, presets and music are not copied into the fresh workspace.
Code, held notes and reference playback stop. Master / chip mixer volume,
the existing AudioContext and keyboard-layout preferences are retained; a cold
reset does not initialize audio or execute starter / example Code.

## Replacement and recovery

The Files adapter prepares and validates a detached fresh project, then follows
the existing workspace / Code retirement APIs. A fresh workspace identity fences
old editor recovery data. Before retirement it captures the flushed old project
and editor state for export or rollback. An explicit false result, exception,
stale operation or cancellation before commit preserves/restores old files,
identity and Code view. Playback already stopped after confirmation is not
automatically restarted on rollback.

Uncommitted replacement state is not saved. A successful explicit New Project
can recover a previously unread storage slot by enabling persistence at commit.
Ordinary failed startup restoration still never overwrites unknown stored data.
Failed final saving is reported as a new in-memory project with local saving
unavailable, with export suggested; it is not reported as saved.

The song-panel reset invalidates pending file reads and selection generations,
aborts controllers, unloads the old player and clears selection, transport,
seek, input and sticky errors. An old import cannot populate the fresh project
or restore stale errors after reset. Later passive imports still work.

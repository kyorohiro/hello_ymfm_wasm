# Analyzer の SSG / PSG 状態表示

作成日: 2026-09-08
状態: 設計案（表示機能は未実装）

## 目的

VGM Analyzer の Operator Info / Channel Monitor に、FM に加えて
SSG / PSG の設定状態を表示する。YM2203 / YM2608 の SSG 再生対応に合わせ、
どのチャンネルでトーン・ノイズ・エンベロープが使われているか確認できるようにする。

## 画面構成

既存の構成案を土台にし、選択された再生音源に応じて必要な項目を表示する。

```text
Operator Info
 ├─ FM
 │   └─ 既存の FM チャンネル表示
 │       ├─ OP1
 │       ├─ OP2
 │       ├─ OP3
 │       └─ OP4
 │
 └─ PSG / SSG
     ├─ YM2203 / YM2608: SSG
     │   ├─ CH A
     │   ├─ CH B
     │   ├─ CH C
     │   └─ 共有設定: Noise / Envelope
     └─ Mega Drive: Sega PSG
         ├─ Tone 1
         ├─ Tone 2
         ├─ Tone 3
         └─ Noise
```

- SSG / PSG を FM のオペレーターとして扱わず、同じパネル内の別セクションにする。
- YM2203 / YM2608 では SSG A/B/C、Mega Drive 再生では Sega PSG を表示する。
- Sega PSG はトーン 3ch に加えて Noise を持つため、3 行だけに省略しない。
- FM オペレーターにある既存の `SSG` 表示は SSG-EG。
  独立した SSG 音源と混同しないよう、FM 側の表示名を `SSG-EG` にする。
- 狭い画面では各チャンネルを縦に並べる。

## 表示項目

### YM2203 / YM2608 の SSG

| 場所 | 項目 |
| --- | --- |
| CH A/B/C | Tone period（生値）、Tone Enable、Noise Enable |
| CH A/B/C | Volume（固定音量 0〜15）、Envelope 使用の有無 |
| 共有 Noise | Noise period（生値） |
| 共有 Envelope | Period、Shape、Continue / Attack / Alternate / Hold |
| 詳細表示 | レジスタ `0x00〜0x0D` の値、直近の変更箇所 |

- Tone / Noise のミキサービットは無効化ビットなので、UI の Enable 表示では反転する。
- Envelope 使用中は固定音量を現在の出力レベルとして表示せず、`ENV` と表示する。
- Tone と Noise が両方無効でも定常出力になる場合があるため、単純に「無音」と判定しない。
- Envelope の Shape への再書き込みは、同じ値でも再トリガーとして変更表示する。
- 周波数・音名の推定表示は追加段階で検討する。実装する場合は VGM のクロックと
  チップのプリスケーラーを反映し、周期 0 の扱いもコアに合わせる。

### Sega PSG

| 場所 | 項目 |
| --- | --- |
| Tone 1〜3 | Tone period（生値）、Attenuation（0〜15） |
| Noise | Periodic / White、周期選択、Tone 3 連動の有無、Attenuation |
| 全体 | 既存の PSG ミュート状態 |
| 詳細表示 | デコード後のレジスタ値、直近の変更箇所 |

- Sega PSG の Attenuation は 0 が最大、15 がミュート。
  SSG の Volume と同じ数値方向として扱わない。
- ラッチバイトと後続データバイトを組み合わせて状態を更新する。
- ノイズが Tone 3 連動の場合、その関係を表示する。
- 未対応の PSG バリアントやステレオ制御を、対応済みの状態として表示しない。

## 状態取得と更新

- 第1段階はレジスタ書き込みを追跡する方式とし、新しい WASM 読み出し API は追加しない。
- YM2203 は `writeYm2203(register, value)` の SSG 範囲を追跡する。
- YM2608 は `writeYm2608(port, register, value)` の port 0 の SSG 範囲を追跡する。
  port 1 の同じ番号は ADPCM-B なので SSG の状態に混ぜない。
- Sega PSG は `writePsg(value)` を追跡する。
- FM 監視と同様に、再生エンジンへ渡す書き込みを監視する。
  元の書き込みを一度だけ転送し、再生を繰り返してもラッパーが重複しないようにする。
- ミュートで書き込みが加工される場合は、VGM が指定した値と再生側のミュート状態を分ける。
- デコードと状態更新を DOM 非依存のモジュールに分離し、単体テスト可能にする。
- 描画は既存の約 120 ms 更新と dirty flag に合わせる。レジスタ書き込みごとに DOM を更新しない。

## 再生位置・リセット

- 初期値は各コアの reset 状態と合わせる。
- 新規ファイル、音源切り替え、先頭からの再生では表示状態と PSG ラッチ状態を初期化する。
- 一時停止では表示を保持する。途中ループでは状態を保持して書き込みを継続する。
- Stop / Reset は既存 FM 表示の方針と揃える。
- 現在の音声生成には先読みがあるため、書き込み監視の表示は聴こえている音より先行し得る。
  初期実装は FM と同じ「生成済み位置の設定状態」とする。聴取位置への厳密同期は別課題。

## 表示の意味と対象外

- 表示対象はレジスタから分かる設定状態。チャンネル別の実音量メーターではない。
- エンベロープの瞬時レベル、ノイズ内部状態、チャンネル別 PCM レベルは
  書き込み追跡だけでは取得できないため、初期実装には含めない。
- 新しいチャンネル別ミュート・ソロ、高レベル Synth API、SSG / PSG の
  JavaScript・MML 出力対応は別課題とする。
- JSON Snapshot には音源種別と SSG / PSG 設定状態を追加する。
  FM 音色用の TFI / VGI 出力には混ぜない。

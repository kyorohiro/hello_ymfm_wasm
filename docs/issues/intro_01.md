# Introduction の今後のコンテンツ案

FM の使い方と、周波数の比からドレミ・音律を考える導入がつながってきた。
次は、音作りから演奏・曲作り・音の加工へ広げていく。

## 現在の入口

- `docs/introductions/index.html`：1 operator での音作り、2 operator の並列・直列・Feedback、アルゴリズム、Analyzer での観察。
- `docs/introductions/tetorica-just-intonation-equal-temperament-ym2612.html`：440 Hz を基準に、オクターブ・単純な比率・純正律・ピタゴラス音律・平均律を聴いて考える。

## 次の候補

### chip 操作

- 高レベル API の操作と、実際のレジスター書き込みを対応づける。
- 周波数、音色、Key On / Off を小さな例で試す。
- 音源の動作を読んで、調べて、再構築する入口にする。

### chord × rhythm

- 同じ和音を同時に鳴らす、順番に鳴らす、分散させる。
- 音の長さ、休符、アクセント、鳴らす間隔を変えて比較する。
- 音の組み合わせに時間を加え、音から音楽へ進む。

### 3度と7度

- 3度・7度を変えたときのコードの性格を聴く。
- 少ない音で和音や進行を表現する。
- 音律で扱った周波数の比と、曲の中での音の役割をつなげる。

### FX guitar basic layout

- ギターの基本的なエフェクト構成を題材にする。
- 歪み、アンプ、空間系などの役割と接続順を試す。
- 一度に1つずつ追加・変更し、何が音を変えたかを聴き比べる。

### FX any

- FM 音源やサンプルなどにもエフェクトを使う。
- 同じエフェクトでも入力する音や接続順によって結果が変わることを試す。
- 正解の設定を覚えるだけでなく、自分の音を探す実験につなげる。

## 進め方

- 次に作る候補は **chord × rhythm**。優先順位は未確定。
- 導入なのでコードはなるべく簡潔にし、何を変えると何が聞こえるかを明示する。
- サンプルで使う関数は、その場で定義と意味が分かるようにする。
- JavaScript を読める形で管理し、埋め込み用の base64 は必要なときに生成する。
- 公開ページの本文・コードコメントは英語に揃える。
- サンプルの補助関数を、説明を省くためだけに web / Playground の共通 API へ追加しない。

# YM2610 / YM2610B VGM再生

更新日: 2026-09-09
状態: 実装・生成WASMの自動テスト完了。ブラウザーの実曲確認は未実施。

## 対応内容

- VGMヘッダー `0x4C` のbit31でYM2610（FM4ch）とYM2610B（FM6ch）を選択。
  クロックはフラグを除いた下位30bitを使用。標準YM2610の有効ハードウェアCHは2/3/5/6。
- `0x58 / 0x59` をPlayerから専用エンジンへ転送。
- SSGの独立出力を左右にミックス。ADPCM-A/Bは独立したROM領域へ接続。
- `0x67` のtype `0x82`（A）／`0x83`（B）を読み込む。
  ROMサイズ・開始位置を検証し、分割ブロックは指定位置へ書き込む。各領域最大16MiB。
- ファイル切替・エンジンresetではROMをクリア。チップ単体reset・途中ループでは保持。
- Analyzerで自動選択、FM/SSGモニター、Note-ish・指板、SSG/ADPCM-A/ADPCM-B On/Off。
  ミュート中も内部の再生状態は進める。
- FMとSSGトーンのMIDI出力。YM2610で無効なFMチャンネルは空トラック。
  PCMからの音符抽出は対象外。
- 配布用WASMを再生成し、AnalyzerパッケージにJS/WASMを追加。

## 確認

生成WASMでSSG、ADPCM-A/Bの発音、左右パン、ミュートを確認。
FMの4ch/6ch差分、VGM ROMの範囲検証・分割転送・2台目除外、Player経由の再スタート、
新規ファイル時のROMクリアを確認。ROM未読込でもゼロ値をADPCMとしてデコードするため、
「未読込なら必ず完全無音」とは扱わず、新規エンジンの未読込出力と比較する。

```sh
node --test docs/playground/ym2610b*.test.mjs docs/playground/ym2608_audio.test.mjs docs/vgm_analyzer/vgm_midi.test.mjs docs/vgm_analyzer/tone_notes.test.mjs docs/vgm_analyzer/psg_monitor.test.mjs docs/vgm_analyzer/source_mutes.test.mjs
```

## 制限

- 複数種類のFM音源の同時再生は対象外。Analyzerの既存音源選択にYM2610/Bを追加した範囲。
- 2台目のYM2610/Bは非対応。2台目ROMブロックは警告してスキップ。
- Timer A/B、タイマーIRQ、CSM、BUSY、外部I/Oのホスト実装は追加していない。
- SSGエンベロープの瞬時音量・自動消音をNote-ish/MIDIで厳密再現しない。
- Playgroundの高レベルSynthは従来のFM操作API。ADPCM高レベルAPI追加は別課題。
- 実機一致・実曲の聴取品質は今回のテストだけでは保証しない。

仕様確認: [VGM v1.71](https://raw.githubusercontent.com/vgmrips/vgmplay-legacy/master/VGMPlay/vgmspec171.txt)、
同梱 `src/ymfm_opn.h` / `src/ymfm_opn.cpp` / `src/ymfm_adpcm.h`。

## ファイル読込時の集計エラー修正

- 実画面で `Unsupported raw VGM command 0x58` が発生。
  再生用 `step()` とは別の `rawCommandLength()` に `0x58 / 0x59` が未登録だったため修正。
- コマンド文脈表示にもYM2610のport・register・valueを追加。
- Analyzerが読込時に使用する集計・ROM一覧・特殊コマンド・文脈解析を両バリアントでテスト。
  ROM内や命令の引数にある `0x58 / 0x59 / 0x66` を命令と誤認しないことも確認。

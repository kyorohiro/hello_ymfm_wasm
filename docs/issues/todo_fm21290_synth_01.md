## 実装・検証済み

| 項目 | 現在の動作と確認範囲 |
|---|---|
| 音源と物理CH | 6OP・32アルゴリズム・16声。AUTOの空き声探索、CH指定と再打鍵、入力元別の離鍵、ペダル保持中の声の再利用を検証した。 |
| Live Coding | `useSoundChip('fm21290')` から音色設定、自動割り当て、物理CH指定、生レジスタ書き込みを併用できる。FilesのRegister Key Onは0x30F1で打鍵・離鍵し、Held Envelopeは押鍵中にEGSのレベル、離鍵後にレートを変える。ChromeでRunとレジスタ列を確認した。 |
| 音色とCassette | Files → presetsから1音色を選ぶ。単音色SysExは1ファイル、32音色SysExはフォルダ内の32ファイルとして取り込む。Exportで現在の音色を書き出せる。旧Cassetteと旧ローカル保存のバンクはRecoveredに展開する。新規Cassetteには標準コード・演奏例・プリセットが入る。 |
| 編集と演奏 | 同じ図で6つのOPのR1〜R4・L1〜L4を編集できる。Chromeで押鍵中のL3変更による出力の増減を確認した。指板、MonacoのRun／Apply、MasterとMixer、波形／スペクトルを実装した。 |
| MIDI | FilesからSMFの選択パートを再生・停止できる。Codeは共通MIDI APIに対応する。詳細パネルは非表示。シーク・ループ境界のゲート復元、CC64、ベンド、模擬ポートの送信列は検証済み。 |
| レジスタと波形 | 記録した書き込み列の再演でPCM一致を確認した。全32経路の倍音、FB量、Algorithm 4／6の帰還、キー同期、キャリア数別の出力補正を試験した。 |
| 制御CPU | v1.8 ROMとEGレベル変換、打鍵速度、鍵盤スケーリング、LFOとModホイールのレジスタ出力を照合した。44.1／48 kHzで変調を比較し、各声のピッチEG、離鍵と再打鍵を検証した。 |
| 時刻指定とLive FX | `build`・`compile`・`schedule`・`clearSchedule` を公開。サンプル単位の書き込み時刻と予約取り消しを検証。scheduled-echo.jsでApplyによる物理CHの変更、liveFxの消音・復帰、StopをChromeで確認。 |
| itch.io配布 | HTML版の単体ビルドと一括ビルドに対応。ZIP直下のindex.htmlから音源、FX、標準サンプルを読み込めることを検証。 |

## 残作業

- [ ] **EGSのアタックと再打鍵** — 弱い打鍵と低いOP出力で、CPUが書く減衰値とEGSが生成する立ち上がり波形を分けて測る。リリース途中に同じ物理CHを打ち直す条件も記録する。
- [ ] **実機との照合** — 測定資料が得られたら、EGの区間時間と絶対音量、帰還履歴のリセット、OPの計算順とタイミング、DACと固定小数点の丸めを照合する。レジスタ仕様に出典・条件・誤差を追記する。
- [ ] **制御CPUとMIDI** — 鍵盤とMIDIを同時に使う場合の受信バッファ動作を調査する。詳細パネルを公開する際はSysExの保存項目と音に反映する項目を明示し、外部機器での受信を確認する。
- [ ] **Browserのオフライン配布** — AudioWorklet、共通JS、標準の音色・コード・MIDI、Monacoとワーカー、ライセンスを揃え、外部通信なしで演奏と補完を検証する。
- [ ] **Tauri版** — FM2610 Desktopの構成を参考にフロントと音源を同梱し、OSの保存ダイアログ、オフライン起動、AudioWorklet、各OSのインストーラを確認する。
- [ ] **公開前の通し確認（後回し）** — 配布物のライセンスと実機未検証項目を点検する。Chrome／Safariで入口から音色選択、演奏、レジスタ操作、Cassette書き出し・復元までを続けて確認する。

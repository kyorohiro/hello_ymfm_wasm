## 1. 標準VABのインポート（先行）

- [x] VAB、および分離したVH＋VBを読む共通パーサーを作る。
  ヘッダー、Program／Tone表、サンプルサイズ表、データ範囲を検証する。
- [x] バンク内のProgram／Tone／サンプルを一覧表示し、Toneを選んで演奏できるようにする。
  初期対応は単一Tone。鍵域によるサンプル切り替えや複数Toneの重ね音は後続とする。
- [x] 元のSPU ADPCM、ループ位置、ADSR1／ADSR2、基準音程、微調整値を既存Synthへ渡す。
  WAVへの変換・再エンコードを避ける。音量・パンの適用方法も確認する。
- [x] ゲーム由来サンプルの終端・ループフラグと、既存`loadADPCM`の検証条件の整合を確認する。
  初回ENDまでの元パケットを保持し、後続paddingを除外。複数LOOP STARTやone-shotのLOOP STARTは未対応として拒否する。
- [x] インポートした音色を既存presetとして保存・再読み込みできるようにする。
- [ ] 既知の標準VABを使い、サンプル境界、ループ、音程、ADSRとブラウザ演奏を検証する。

## 方針

- 万能な`psf2vab`を先に作るのではなく、VABパーサーとPSF抽出層を分けて共用する。
- PSFは実行形式であり、すべての作品が標準VABを含むわけではない。
  標準VABが展開後データに含まれる場合はCPUエミュレーションなしの静的抽出を目指す。
- VAG単体では楽器のADSRや基準音程が揃わないため、元の設定を完全復元できるとは扱わない。
- 初期目標は音色の取り込みと試奏。曲の完全再生や、ゲーム内ドライバの全挙動の再現は別課題。

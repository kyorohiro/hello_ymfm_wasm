# Devlog下書き：音源チップを、レジスタから鳴らす

Tetorica Playgroundに、Game Boy音源を低レベルで操作する入口を追加しました。

```js
const gb = await createSoundChip('gameboy');
gb.writeRegister(0x16, 0x80); // APUを有効にする
```

矩形波2チャンネル、波形メモリー、ノイズ。音源レジスタに値を書き込み、
チップ固有の仕組みで音を作れます。ゲームROMは必要ありません。
今回のGame Boy対応はレジスタ操作が中心で、音名や楽器を指定する高水準APIはこれからです。

examplesには `chip-raw/` を追加しました。`basic/` の次に並ぶ、
音源チップの中身に触れるための入口です。

- `ym2612-raw-write-beep.js`：FMのオペレーターやエンベロープを設定して発音。
  画面の音源選択をYM2612にして実行します。
- `gameboy-raw-write-sample.js`：独立したGame Boy音源を作り、4種類の音を順番に試聴。
  画面で選んだ音源と併用できます。

ライブコーディングでフレーズを組み立てながら、必要ならレジスタまで降りて音を作る。
Sonic Piから着想を得た書き心地に、Tetoricaでは「音源チップそのものを触る」
楽しさを加えていきます。FM、波形メモリー、ノイズ生成器。それぞれの制約や癖も、
音作りの材料にできるPlaygroundを目指しています。

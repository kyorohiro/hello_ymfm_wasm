# FM 音色探索用 WAV の初期データセット案

## 目的

[sound-color-01.md](sound-color-01.md) の音色探索を検証するため、
既知の YM2612 パラメーターから WAV と設定メタデータを生成する。
まず小さな候補集で、生成・試聴・特徴量比較を一通り回す。
以下は生成仕様の案であり、生成機能・データセットは未実装。

## 初期スコープ：2op FM の108設定

音程・長さ・エンベロープを固定し、モジュレーター倍率と TL だけを粗く振る。
全パラメーターを同時に変更せず、どの変更が音と指標に影響したかを追えるようにする。

| 項目 | 初期設定 |
| --- | --- |
| 音源 | YM2612、既存の ymfm を利用する方向で検討 |
| 接続 | モジュレーター → キャリアの1組。他の出力はミュート |
| 基準音 | A3 = 220 Hz |
| キャリア倍率 | 1 固定 |
| モジュレーター倍率のレジスタ値 | 0, 1, 2, 3, 4, 6, 8, 12, 15（0は0.5倍） |
| モジュレーター TL | 0, 8, 16, 24, 32, 40, 48, 56, 64, 80, 96, 127 |
| キャリア TL | 24 固定。生成時にクリッピングを確認 |
| Feedback | 0 固定 |
| Detune / LFO / SSG-EG | 無効 |
| エンベロープ | 速い立ち上がり、キーオン中は一定、短いリリース |
| キーオン長 | 1秒 |
| キーオフ後の収録 | 0.5秒 |
| WAV | 44.1 kHz、モノラル、16 bit PCM |

9倍率 × 12段階の TL = **108設定・108 WAV**。
1ファイル1音とし、総収録時間は約1.5秒。
キーオフ後0.5秒で十分に減衰しているか確認し、不足する場合は収録条件を見直す。

モジュレーター TL は変調の強さを変え、音色に影響する。
キャリア TL は出力音量にも影響するため、最初は固定する。
TL は大きいほど減衰が大きく、8刻みは振幅の線形な8段階ではない。

YM2612 の4op構成から1組を使うため、実装時にアルゴリズム・使用スロット・
ミュートする出力を確定する。未使用キャリアだけでなく、意図しない変調経路が
残っていないことを確認する。アルゴリズム番号と全オペレーター設定を保存する。
AR / DR / SR / SL / RR 等の具体値も生成器実装時に確定し、曖昧な名称だけで保存しない。

## 生成条件と再現性

- ファイルごとに音源をリセットし、全設定を書いてからキーオンする。
- 音源クロック、出力ゲイン、リサンプリング条件を固定する。
- WAV は固定ゲインで保存する。音量正規化は解析時に行う。
- クリッピングがあれば、候補ごとの音量補正ではなく共通ゲインを見直す。
- A3 の目標周波数に加え、実際に書いた BLOCK / FNUM を記録する。
- キーオン・キーオフ位置を出力サンプル単位で記録する。
- 波形生成は再生デバイスや実時間の待ち時間に依存しないオフライン処理にする。
- 同じ設定で再生成した結果が一致するか検証する。

## 保存するメタデータ

各 WAV に対応する JSON を保存し、全件を辿れる一覧も用意する。

- 設定 ID、WAV ファイル名。
- YM2612 クロック、サンプルレート、PCM形式、モノラル化方法、出力ゲイン。
- 音名、目標周波数、BLOCK / FNUM。
- キーオン長、キーオフ位置、収録フレーム数。
- アルゴリズム、Feedback、使用チャンネル、オペレーターの番号体系。
- 全オペレーターの倍率・TL・Detune・エンベロープ等の設定。
- LFO、SSG-EG、その他の固定設定。
- データセット仕様の版、生成器と合成コアの版・コミット。
- 生成結果のピーク、RMS、クリッピングの有無。

後から音色を再現できることを優先する。探索対象の2項目だけではなく、
固定した値と未使用オペレーターの状態も記録する。

## 段階的な拡張

### 1. 音域を追加

同じ108設定を A2 / A4 でも生成し、A3 と合わせて **324 WAV** にする。
音域での聞こえ方と特徴量の変化を確認する。
類似度は原則として同じ音程同士で比較する。

### 2. 上位候補の周辺を細かく生成

近い候補が見つかったら、例えばモジュレーター TL を8刻みから2刻みにする。
最初から全範囲を細分化せず、粗い検索から詳細探索へ接続する。
倍率は離散レジスタ値なので、利用可能な値の範囲で探索する。

### 3. エンベロープを追加

キャリアとモジュレーターの減衰を別々に変える。
音量の減衰と、倍音分布の時間変化を分けて評価する。
まず少数の明示的な設定を選び、全レジスタの総当たりはしない。

### 4. Feedback / 4op / 別アルゴリズムへ拡張

2opで生成と比較が機能することを確認してから範囲を広げる。
初期108設定だけで、任意の音を十分に近似できるとは想定しない。

## 最初の検証

- [ ] 2op接続、具体的なエンベロープ値、クロックとゲインを確定する。
- [ ] 108設定の組み合わせを生成し、IDの重複・設定漏れがないことを確認する。
- [ ] 各設定から WAV / JSON と一覧を生成する。
- [ ] 再生成の一致、長さ、無音、クリッピング、意図しない音の混入を確認する。
- [ ] 倍率と TL を変えた音を聴き比べる。
- [ ] RMS と2種類の log 振幅スペクトログラムを計算する。
- [ ] 同一 WAV の距離がゼロになることを確認する。
- [ ] 近い設定・異なる設定の順位を試聴結果と比較する。
- [ ] 波形が同じになる設定は失敗扱いせず、同等候補として扱う。
- [ ] 粗い候補集に含まれない設定の WAV を入力し、近似検索を試す。
- [ ] A2 / A4 を追加し、音域による違いを確認する。

比較スコアが低くても耳で似ているとは限らない。
候補を再生して確認できる状態で、特徴量と評価の重みを調整する。

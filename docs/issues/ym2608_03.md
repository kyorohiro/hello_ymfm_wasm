# RF5C164 対応 — Mega-CD の PCM 再生

更新日: 2026-09-08
状態: VGM Player / Analyzer への初期実装完了。実曲聴取・ブラウザー目視確認は未実施。

## 実装した段階

1. **WASM / JS**: MAME の RF5C164 処理を独立化し、低レベル API を追加。
2. **VGM 接続**: VGM パーサー → Player → Genesis エンジンを接続。
3. **動作確認**: 元コードとの出力比較、生成済み WASM、合成 VGM、既存の関連テストで確認。

既存の YM2612 + Sega PSG に、VGM ヘッダーで使用が指定された場合だけ
RF5C164 を追加する。Analyzer では `MEGA-CD` と表示し、`PCM On / Off` を追加。
PCM 単独の VGM も同じ経路で再生できる。

## コアと API

- 採用元: [MAME RF5C68 / RF5C164](https://github.com/mamedev/mame/blob/d0f1c15a0f6df2dd51a754cb46e6175b7079c8f2/src/devices/sound/rf5c68.cpp)。
- 固定リビジョン: `d0f1c15a0f6df2dd51a754cb46e6175b7079c8f2`。
- [独立化したコア・採用メモ](../../third_party/mame-rf5c164/README.md)。
  元ソースも `upstream/rf5c68.cpp` に保存。BSD-3-Clause の著作権表示・ライセンスを同梱。
- MAME のデバイス・アドレス空間・音声ストリームへの依存を外し、
  8ch、64 KiB RAM、RF5C164 の16 bit ミックス出力を使用する。
- 出力レート変換はクロック / 384 を基準とした sample-and-hold。
  位相と端数はバッファをまたいで保持する。MAME 全体のリサンプラーは移植していない。
- [WASM 窓口](../../wasm/rf5c164_wasm.cpp) と [JS API](../../web/rf5c164.js)。
  `Rf5c164.create()`、`writeRegister()`、`writeMemory()`、`loadMemory()`、
  `loadBankedMemory()`、`readMemory()`、`read()`、`generateStereo()`、`reset()`、`dispose()`。
- `loadMemory()` は絶対アドレス。`writeMemory()` は4 KiB のバンク窓。
  VGM 用 `loadBankedMemory()` は開始位置と選択バンクを OR して連続転送する。
- チップ単体 `reset()` は RAM を保持。`clearMemory()` は明示的に RAM を消去。
  Player の新規ファイル読込時には RAM を消去し、先頭からの再生では
  エンジンが RAM・レジスタ・リサンプラーを初期化する。
  途中ループでは RAM と発音状態を保持する。

MAME 冒頭にはチップ差分を確認する TODO が残っているが、RF5C164 用の設定・実装は存在する。
この TODO だけから具体的な発音不具合があるとは判断しない。

## VGM 対応

| 項目 | 実装内容 |
| --- | --- |
| Header `0x6C` | RF5C164 クロック。古い・短いヘッダーは未使用扱い |
| Command `0xB1` | レジスタ書き込み |
| Command `0xC2` | バンク窓への1バイト書き込み |
| `0x67` / type `0xC1` | 16 bit 開始位置付き RAM ブロック転送 |
| `0x67` / type `0x02` | RF5C164 データバンクへの追記・連結 |
| `0x68` / type `0x02` | データバンクから PCM RAM への転送 |

- RAM 転送は VGM の命令順・wait の位置で反映。途中のサンプル差し替えに対応。
- RF5C164 バンクの同じブロックを途中ループで重複蓄積しない。
  この変更は RF5C164 のバンクに限定し、既存 YM2612 DAC バンクの管理は変更していない。
- 切れたブロック、不正な転送元・転送先範囲はエラー。
  `0x68` の長さ 0 は 16 MiB と解釈した上で範囲検証する。
- 2台目の RF5C164 への書き込み・データは警告してスキップ。
- RAM ブロックのバンク OR は [libvgm の DoRAMOfsPatches / Cmd_DataBlock / Cmd_PcmRamWrite](https://github.com/ValleyBell/libvgm/blob/master/player/vgmplayer_cmdhandler.cpp) に合わせた。
  命令形式は [VGM Specification](https://vgmrips.net/wiki/VGM_Specification) を参照。

## Analyzer / Genesis エンジン

- [GenesisAudioEngine](../../web/genesisaudioengine.js) に任意の PCM コアを追加。
  `rf5c164ModuleFactory`、`rf5c164ModuleOptions`、`rf5c164Clock` を指定して生成する。
- Analyzer は PCM 使用時に WASM を読み込み、ヘッダーの各クロックを渡す。
  音源構成・クロックが変わった場合はエンジンを再生成する。
- PCM の On/Off は出力ミックスだけに作用し、Off 中も再生位置を進める。
  全音源ミュート判定と Snapshot の `sourceMutes` に PCM を追加。
- `web/` と `docs/js/` の対象ファイルを同期し、生成済み WASM を `docs/generated/` に追加。
  Analyzer / Web runtime 配布スクリプトに JS とライセンスの収録を追加。

## 動作確認

```sh
sh scripts/build_rf5c164_wasm.sh
python3 scripts/verify_rf5c164_reference.py
node --test docs/playground/rf5c164_audio.test.mjs docs/playground/ym2608_audio.test.mjs docs/playground/vgm_export.test.mjs docs/vgm_analyzer/*.test.mjs
```

- 元コード比較: 固定した MAME ソースから発音・レジスタ関数をそのまま取り出し、
  フレームワーク部分をテスト用に置換。共通レートで移植コアと比較し、
  **48,095 ステレオフレームが一致**。
  8ch、パン、再生ステップ、ループ、On/Off、途中書き込みを含む。
  MAME アプリ全体や実機との比較ではない。
- 生成済み WASM: 符号、パン、ループ、RAM 保持・消去、
  分割バッファでも一致するリサンプラー出力を確認。
- 合成 VGM: C1 ブロック、C2 書き込み、バンク OR、分割バンクからの68転送、
  wait を挟んだサンプル差し替え、再スタート、一時停止状態・再開、途中ループ、曲切替を確認。
- Genesis: 実際の YM2612 / PSG / RF5C164 WASM を組み合わせて発音確認。
  PCM ミュート解除後の位相は、連続再生したコアとの比較でも確認。
- 不正データ、2台目、未対応 DAC stream が YM2612 に誤転送されないことを確認。
- **関連53テストが通過**。JavaScript・シェル構文、差分の空白エラーも確認。
- 接続可能なブラウザーがなく、画面操作・実曲聴取は未実施。

## 2026-09-08: RF5C164 の状態表示

- Operator Info の Sega PSG の下に `RF5C164 PCM` パネルを追加。
- VGM ヘッダーに基づく Used / Not used、クロック、チップ ON/OFF、
  チャンネル有効数、レジスタ書き込み回数、RAM 転送回数・累計バイト数を表示。
  転送バイト数は上書きも含む累計で、RAM の使用容量ではない。
- PCM 1〜8 の ON/OFF、音量、左右パン、再生ステップ、開始・ループアドレスを表示。
  チャンネルの ON は設定値であり、実際の発音・実音量を示すものではない。
- 再生エンジンの成功した書き込みを監視し、選択チャンネルと RAM バンクを分けて追跡。
  同じエンジンを繰り返し監視しても、書き込みを重複転送しない。
- PSG と同じ約120 ms更新・変更ハイライトを使い、先読みした生成位置の状態を表示。
  先頭からの再生・停止・曲切替で初期化し、途中ループでは保持。
- JSON Snapshot に `rf5c164` の設定状態を追加。
- `rf5c164_monitor.test.mjs` と既存の PSG・ミュート・RF5C164 音声テスト、計17件が通過。
  ブラウザーでの表示・操作確認は未実施。

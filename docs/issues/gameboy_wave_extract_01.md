# GB Info：Game Boy の波形・発音時設定を取り出す

VGM Analyzer の **GB Info → Analyze Game Boy voices** で、Game Boy CH3 の波形メモリーを一覧に表示する。

- 16バイトを上位ニブル・下位ニブルの順に展開した32点（各0〜15）。
- 波形グラフと32点の JavaScript を表示。
- **Copy setWaveform JavaScript** で `gb.wave.setWaveform([...]);` をコピー。
- **Save waveform JSON** で32点、元の16バイト、観測時刻を保存。
- 同じ波形はまとめ、書き換え後の異なる波形は別の項目として表示。

コピー先では Game Boy 音源を `gb` として取得し、波形設定後に `setLevel()`・`setNote()`・`keyOn()` を指定する。波形設定そのものは発音を開始しない。

抽出対象は **VGM に書かれた wave RAM のスナップショット**。同時刻の連続した書き込みをまとめ、wait の直前・CH3 trigger 書き込み・ファイル末尾で記録する。音程や音量、実際の発音期間を含む音色全体の再現ではない。

最初の16バイトが揃わない状態は推測で0埋めせず、抽出から除いて説明を表示する。一度全バイトが判明すれば、部分的な更新も反映する。DMG の発音中の RAM アクセス制限やトリガーによる RAM の変化はエミュレートしていないため、観測した書き込みと実際に鳴った波形が一致しない場合がある。VGM ループは展開しない。第2 Game Boy チップは既存パーサーの制限により未対応。

共通のサンプル抽出 API でも `written-wave-ram` として一覧・JSON保存を利用できる。波形単体には再生ピッチや長さがないため、この項目の WAV 書き出し・試聴は提供しない。


## Pulse・Noise の発音時設定

Game Boy 選択時は Sample Explorer のタブ枠を **GB Info** に切り替え、Pulse CH1／CH2、Wave CH3、Noise CH4 ごとに表示する。他のチップでは従来の Sample Explorer に戻る。

- Pulse：デューティ比、初期音量、エンベロープ方向・周期、CH1 のスイープ。
- Noise：初期音量、エンベロープ方向・周期、分周値、シフト、LFSR幅。
- **Copy initial voice JavaScript**：既存の `gb.pulse.setVoice()`／`gb.noise.setVoice()` と、判明しているCH1スイープの設定コードをコピーする。
- **Save voice and changes JSON**：初期設定と各発音の後続書き込みをまとめて保存する。

同じチャンネルの同じ音色設定をまとめる。音程・長さ設定の違いは各 trigger の情報として保持する。発音の選択欄から、初期レジスター、長さ有効ビット、最後に書かれた length load、音程レジスター、DAC・電源状態、後続書き込みを確認できる。

後続書き込みは trigger を基準とした相対時刻を付け、初期設定とは別欄に表示する。区間は次の trigger、DAC無効化、電源OFF、ファイル末尾で閉じる。自動エンベロープ・スイープ・長さカウンターによる変化はエミュレートしないため、区間は実際に音が鳴っていた長さを示さない。

未記録の必須音色レジスターがある trigger は除外する。他の不明な項目は null とし、既定値を推測で埋めない。コピーコードは音色の初期設定のみで、音程、長さカウンター、左右出力・マスター音量、後続の書き換えは適用しない。現在の高レベル `keyOn()` は長さ制限を無効化するため、元VGMの長さ設定も自動復元するコードとはしない。

共通サンプル抽出 API の表現名は `trigger-register-settings`。JSONでエクスポートできるが、Pulse・Noise設定のWAV化や試聴は今回の対象外。

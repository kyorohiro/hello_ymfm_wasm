Tetorica: ギター指板ベースの音高表示を実装してください

現在、各CHの音高表示にはピアノロールを使っています。
ただし、音域全体を表示するには縦方向のスクロールが必要になり、
再生中に「今どの音が鳴っているか」を一覧で確認しづらい状態です。

そこで、ピアノロールの代わりにギター指板ベースの表示を試してください。

目的
- CHごとに独立したギター指板を表示する
- 再生中、そのCHで現在鳴っている音を指板上でハイライトする
- できるだけスクロールせず、広い音域を一覧できるようにする
- 実際のギター演奏用TABを作ることが目的ではない
- ギター指板を「コンパクトな音高可視化UI」として利用する

表示仕様
- 1CHにつき1つの指板を持つ
- 横方向は0〜24フレット程度を基本とする
- 必要に応じて6弦だけでなく7弦、8弦も利用できる構造にする
- 低い音は低音弦側、高い音は高音弦側に表示されるようにする
- 現在鳴っているノートが一目で分かるようにハイライトする
- Note Off時にはハイライトを解除する
- 同時発音がある場合は複数ノートを同時に表示できるようにする

重要:
これはギターの自然な運指を再現する機能ではありません。
「同じ音高は常に同じ指板位置に表示される」ことを優先してください。

音高から指板位置へのマッピング

ギターでは、例えばC4のような同じ音高でも、
弦とフレットの組み合わせが複数存在します。

そのため、MIDI Note / Note Name から指板上の候補をすべて取得したあと、
以下の固定ルールで表示位置を1つに決定してください。

候補選択ルール

1. 可能な弦・フレット位置をすべて列挙する

例:
C4 が複数の弦で出せる場合、それぞれを候補として取得する。

2. 低い音域では低音弦側を優先する
   高い音域では高音弦側を優先する

音高が上がるにつれて、
6弦 → 5弦 → 4弦 → 3弦 → 2弦 → 1弦
の方向へ自然に移っていくようにする。

7弦・8弦を使用する場合も同様に、
最も低い弦から最も高い弦へ音域を分担させる。

3. 同じ音について表示位置が毎回変わらないようにする

直前のノート位置や演奏状況によって配置を変更しないこと。

例えばC4なら、
いつ再生しても必ず同じ弦・同じフレットに表示されるようにする。

音高 → 指板座標 は決定的な関数にしてください。

4. なるべく低いフレットを利用する

弦の担当音域が同程度で候補が複数残る場合は、
基本的にフレット番号が小さい候補を優先する。

ただし「最低フレット優先」だけで決めると、
音高の変化に対して弦を頻繁にまたぐ可能性があるため、
まず音域に応じた弦の優先順位を決め、
その後にフレット番号を比較してください。

5. 24フレット以内を優先する

基本表示範囲は0〜24フレットとする。
24フレット以内で表現できる候補を優先する。

対象音域によって6弦で不足する場合は、
7弦・8弦を利用できるようにする。

実装について

既存のNote / MIDI Note表現はできるだけそのまま利用してください。

音高と指板座標の変換処理はUIから分離し、
例えば以下のような純粋関数として扱える構造にしてください。

noteToFretPosition(note) -> {
  stringIndex,
  fret
}

または

getFretCandidates(note)
selectFretPosition(note, candidates)

のように、
候補生成と候補選択を分離しても構いません。

マッピング部分は単体テスト可能にしてください。

確認したいケース
- 低音が低音弦側に配置される
- 高音が高音弦側に配置される
- 同じ音は常に同じ座標になる
- 0〜24フレットの範囲を優先する
- 6弦で不足する音域を7弦・8弦で扱える
- Note On / Note Offで表示が正しく更新される
- 複数音の同時表示ができる

まず既存のピアノロール表示とNoteデータの流れを確認してください。

大規模な作り直しはせず、
現在の音高表示部分だけをギター指板表示へ差し替えられる構成で実装してください。

既存コードの設計・命名・状態管理方式を尊重し、
必要のないリファクタリングや周辺コードの変更は行わないでください。

## 実装（2026-09-08）

- Note-ish の `Channel pitch display → Fretboard` で各CHの鍵盤部分を指板へ切り替える。
  上の履歴グラフと Normal / Detailed の選択は独立して維持する。
- 0〜24フレット、6／7／8弦を選択可能。初期値8弦。全幅に収め、音高を追うスクロールはしない。
- 標準の開放音を使用。6弦 E2〜E6、7弦 B1〜E6、8弦 F#1〜E6。
  範囲外は上下矢印と音名で示し、丸めやオクターブ移動はしない。
- 担当音域は下記の固定バンドに変更。低音は4〜6弦、高音は1〜3弦に分散する。
  候補生成後、担当弦への近さ、フレット番号の順で選択する。
  同じ音は固定位置となり、低音弦を追加しても既存音の弦番号・フレットは変わらない。
  内部 stringIndex は低音側から0始まり、画面の弦番号は高音側を1とする。
- 現在音を最寄りの半音にして青で表示。KEY OFFでは解除する。セント表示は既存欄に残す。
- `fretboard.js` は純粋関数として音高マッピングと複数音の描画を提供。
  現行のFMモニターから渡す音は1CHにつき1音。実際のポリフォニー抽出は追加していない。
- マッピングの全対応音域、決定性、弦追加時の位置維持、範囲外、複数音、KEY OFFをテスト。

### 担当音域の調整

実際の標準チューニング・24フレット以内を維持。近い音は同じ弦にまとめ、
高音域では3→2→1弦へ進み、オクターブ境界で低い弦へ戻さない。
隣接半音間のフレット差を最大4に抑える。高音端では1弦上で徐々にポジションを上げる。
以下は入力例の重複・逆順を調整した暫定の固定割り当て。

| 弦 | 担当音域（両端を含む） |
| --- | --- |
| 6 | E2〜B2 |
| 5 | C3〜F3 |
| 4 | F#3〜B3 |
| 3 | C4〜F4 |
| 2 | F#4〜B4 |
| 1 | C5〜E6 |
| 7（追加） | B1〜D#2 |
| 8（追加） | F#1〜A#1 |

同音の座標は演奏履歴に依存しない。弦追加でも既存音の弦番号・フレットを維持。
全対応音の実音高・範囲、低音／高音の弦分担、隣接音のバンド、KEY OFFを含む4テスト通過。


- 隣接半音の移動幅を全対応音域・6／7／8弦で検証。B4→C5は2弦12→1弦8フレット。
- 固定配置のため、大きい音程跳躍での移動幅やフレーズ全体の運指幅を4フレットに制限するものではない。
- 同音固定・実音高・弦分担・Note Offを含む指板テスト6件通過。
- キャッシュ対策の読み込み番号も更新。実画面・実曲での確認は未実施。

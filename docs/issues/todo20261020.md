# Playground：共有Keyboard入力とSample Editor

作成日：2026-10-20
状態：共有KeyboardとSample Editorの初期実装済み。Mega CD／Game Boy／PC98／Neo Geoで利用できる。

## 今回の実装と使い方

- Menu → **Sample Editor…** で素材を作成・編集する。録音は最大60秒、ファイルは64 MiB・モノラル／ステレオ・5分まで。
- 各modeの `*-sampler.js` をRunすると、保存した素材がGuitar形式の **Keyboard** へ接続される。
  未保存なら最初にSample Editorが開く。保存後のRunは入力画面を省略する。
- `/samples/sampler.sample.json` と同名の `.wav` に、編集設定と元のFloat32 PCMを別々に保存する。
  FILESの `.sample.json` を開けば再編集でき、Cassetteにも含まれる。
- 選択範囲・ゲイン・ノーマライズ・フェード・ループ・基準音・cent調整、Undo／Redo、
  音程推定、一周期抽出、マウスでの波形編集を用意した。
- 元の選択範囲と編集後PCMを画面内で試聴し、Run後のKeyboardで楽器として試奏する。
- Game Boyを選ぶと、編集後の選択範囲と変換後の32点・4bit波形を並べて表示する。
  **Preview Game Boy**は独立した実Game Boyコアで基準音を0.85秒試奏する。
  表示・試奏・保存後の楽器は同じ波形変換を使う。プレビューは標準Game Boy音量を使い、
  演奏中のチップの設定やMixerを変更しない。基準音はC1（MIDI 24）以上。
- Instrumentの選択は変換先の種類ごとに記憶する。別のmodeへ同じ素材を移した時は、そのmodeの標準変換先を使う。

```js
const audio = await inputAudio({asset: '/samples/sampler.sample.json', edit: false});
if (audio) keyboard.bind('sampler', await createSampleInstrument(audio));
```

独自の楽器も `keyboard.bind(name, {noteOn, noteOff, allNotesOff})` で接続できる。
各音には `{id, midi, velocity}` が届き、同音を別の弦で押した場合もIDで区別する。
`keyboard`／`inputAudio`／`createSampleInstrument` は `pg` 経由でも使える。

## 2026-10-21：チップタブ上でのKeyboard試奏

OPN系に加え、Game Boy／NES + FDS／YM2151／HuC6280／DX7／OPL／OPLL／AY／
Sega PSG／RF5C164／OKIM6258の各チップタブでも、右下のGuitar操作とPCキーで試奏できる。
対象は表示中のインスタンスと選択中CHで、音色・波形・読み込み済みサンプルをそのまま使う。
Sega PSGにも試奏CHの選択を追加した。CH・インスタンス・タブ変更時は保持音を解放する。
下側Keyboardの手動ルートやスクリプトの楽器接続は、タブ内試奏とは独立して保持する。
新たな音声ノードや更新タイマーは追加せず、キー入力を理由とするviewの読み取りも行わない。
32X PWMは時刻付きPCMストリームで独立した音程付きチャンネルを持たないため、この試奏の対象外。

## 目指す体験

既存のGuitar形式のKeyboardを、そのままサンプラーや各modeの音源へ接続できるようにする。
弦・フレット・ポジションといった入力方法を保ち、発音先を選べるようにする。

録音機能は、Mega CDのExampleから使い始めた入口を土台に、各modeで共有する
Sample Editorへ育てる。基本の操作は次の流れにする。

**録音／ファイル読込 → 波形で範囲選択 → 音量・音の端を調整 → 基準音を指定 → Keyboardで試奏 → Cassette保存**

長めに録音して必要な部分を選べること、録った声や描いた波形から楽器を作れることを重視する。
挙げた機能は候補であり、一般的なサンプラーの操作を参考に、使いやすい構成へ整理する。

## 実装前にあったもの

- `inputAudio()`／`pg.inputAudio()`：ファイル選択・マイク録音とキャンセル処理がある。
  現在の録音上限は既定5秒で、成功時はデコード済みPCMを返す。
- Mega CDのサンプラーExample：切り出し、モノラル化、リサンプル、音の端のフェード、
  RF5C164への転送、PCキーボードによる8音の割り当てがある。使用素材は最大3秒。
- Guitar形式のKeyboard：配置データにMIDIノート番号がある。
  現在の発音処理とチャンネル選択はFMの試奏へ結び付いている。
- RF5C164の音源タブ：波形表示、Start／Loopのドラッグ、音量・速度・試聴がある。
  現在の位置指定はRF固有のRAMアドレスなので、共有UIでは素材中の位置として扱う。
- Game Boyの32点波形編集と、BRR素材の音程推定処理がある。
  それぞれ対象音源に依存しており、汎用化する部分を切り出す必要がある。

## 共有Keyboard入力

Guitar、画面上のキー、PCキーボードから、共通の音楽的な入力イベントを出す。
将来の外部MIDI入力も、同じ発音先へ接続できる形を目指す。

- 押した音をMIDIノート番号として渡す。ベロシティも扱える形にする。
- 発音先は、FM試奏、RF5C164サンプラー、ADPCM、Game Boyの波形音源などへ差し替える。
- 発音数とボイスの割り当ては接続先の楽器が担当する。
  FMのチャンネル・プリセット指定は、FMへ接続した時に使う。
- キーの下に表示するFM固有のblock／fnum情報は、接続先に合わせて表示を切り替える。
- 非FM modeでも、接続先があれば同じKeyboardを使えるようにする。

接続APIは `keyboard.bind(name, {noteOn, noteOff, allNotesOff})` とした。
発音・消音は非同期処理にも対応し、Main／Workerで同じ契約を持つ。

### 入力の寿命と音の所有者

- 音番号とは別の押下IDを持つ。同じ音でも、異なる弦・フレットから同時に押せるため。
- ボイスを別の音へ割り当てた後、以前のキーの解放で新しい音を消さない。
- Stop、Runの置き換え、接続先変更、指板変更、フォーカス喪失で押下状態を解放する。
- ポインターが元のキーの外へ出ても、解放・キャンセルを受け取れるようにする。
- 編集欄への文字入力では発音せず、発音済みのキーの解放は受け取る。
- 非同期の準備完了や古いWorkerの応答が、次のRunで発音しないようにする。

## Sample Editor

### 最初に揃える編集機能

- [x] ファイル読込と、用途に合わせて上限を決められる長めの録音。
- [x] 波形表示、ズーム、スクロール、使用範囲の開始・終了マーカー。
- [x] 選択範囲の試聴と、Run後のKeyboardから変換後のチップでの試聴。
- [x] 音量調整、ノーマライズ、クリッピングの表示。
- [x] フェードイン／アウト。音の端を突然切ってクリックを作らない操作。
- [x] 基準音の手動指定と、cent単位の微調整。
- [x] Undo／Redo、元の素材へ戻す操作。
- [x] 編集した素材をKeyboardへ割り当て、Cassetteへ保存する操作。

録音上限はチップのRAM容量と分けて考える。元の録音から選択した部分を、
転送先の容量・レート・形式へ変換する。録音時間やメモリー使用量の上限は実装時に決める。

### 次に広げる機能

- [x] ループ範囲の指定とPCM試聴。一周期抽出時は近くのゼロクロスを使う。
- [ ] 任意のループマーカーのゼロクロス吸着と、境界の比較・微調整。
- [x] 単音の周波数・音名・オクターブ・cent差の推定と、候補を基準音へ反映する操作。
- [x] 一周期の選択・抽出と、マウスによる波形の手描き。
- [x] 波形の拡大時にサンプルを直接修正できる編集。
- [x] Game Boyの32点・4bit変換後波形と編集後の選択範囲を比較し、画面内で実コア試奏する。
  他のチップの変換後表示・試奏への展開は別途。

音程推定は候補と確かさを表示し、手動で補正できるようにする。
声の揺れ、倍音の強い音、ノイズ、打楽器、和音では、オクターブ違いや推定不能を扱う。
サンプルレートと基準音は別の情報として保持する。

## 共通素材とチップごとの変換

元のPCMと編集設定を共通で持ち、最後に音源ごとの形式へ変換する。
同じ素材を別のmodeへ持っていった時にも、元音から作り直せるようにする。

| 対象 | 素材の使い方・制約 |
| --- | --- |
| Mega CDのRF5C164 | PCMへ変換。8音で64 KiB RAMを共有する。終端ガード込みで選択素材は最大65,504フレーム。超過時は範囲／レートの調整を求める。再生速度で音程と長さが一緒に変わる。 |
| PC98のYM2608 ADPCM-B | PCMからADPCM-Bへ変換する既存経路を使う。音程変更可能な1音として扱う。 |
| NeoGeoのYM2610／YM2610B ADPCM-B | 同じPCM変換経路を使い、256バイト境界へは無音PCMを追加してからエンコードする。音程変更可能な1音。ADPCM-Bのループは素材全体のみで、部分ループは明示的に拒否する。 |
| NeoGeo ADPCM-A | 6音の固定レート再生。音程変更とハードウェアのループ再生を持たず、キーごとの打楽器・素材割り当てに向く。PCMからのエンコーダーは今後の実装対象。 |
| Game Boy Wave | 一周期を選び、32点・4bitの波形へ変換する。波形チャンネルは1音。 |
| 将来候補：PC Engine／SNES | PC Engineは周期波形への変換を検討する。SNESはBRR変換が必要で、PCMからのエンコーダーは未実装。 |

選択範囲、ループ、音量、基準音などの編集情報は共有し、
容量・配置境界・量子化・同時発音数などはチップ側で確認する。
変換後の使用バイト数、音の長さ、実際のループ位置を表示し、収まらない場合は調整できるようにする。

## 素材と編集情報の保存

- 元の録音／読込素材を、再編集できる音声ファイルとしてVirtual Filesへ保存する。
- 使用範囲、ループ範囲、ゲイン、フェード、基準音、手描き編集などを別の編集情報として保存する。
- 保存形式は元のFloat32 WAVと、`format: "tetorica-sample-v1"` のJSON。JSONに `sourcePath`、`settings`、`name`、`source` を持つ。
- チップへ変換したデータは元素材から作り直せるようにする。
- Cassetteを開き直した時に、素材・編集状態・楽器への割り当てを復元する。
- 元の試聴とチップ変換後の試聴を使い、量子化や圧縮による変化を確認できるようにする。

## 演奏・編集・画面更新の分け方

Keyboardの試奏には、音楽コードの先読みスケジュールと区別した低遅延の経路を用意する。
MainとWorkerで同じ操作・発音・解放の意味を持たせる。

波形解析、音程推定、リサンプル、チップ用エンコードは、編集の確定時や適切な背景処理で済ませる。
演奏時には準備済みの楽器へ発音・消音を送り、重い変換と画面の再描画を演奏処理から分ける。
表示フレームごとに音源へ波形全体を送り直したり、音声イベントから重い描画を直接行ったりしない。
編集確定・変換完了・プレビュー開始など、境界のあるイベントで連携する。

実装では波形の概要・解析・リサンプルを専用Workerに任せ、表示は変更時だけrequestAnimationFrameで描く。
Keyboardは通常のliveLoopの先読みを経由せず、各押下の寿命を持つ即時経路を使う。
Stopや接続先変更で未完了の発音を取り消す。試聴の開始・停止には短い音量ランプを入れる。

## 実装順

1. **共有Keyboard入力**：既存Guitarの配置を保ち、FM試奏とMega CDサンプラーの接続先を切り替える。
2. **共有Sample Editorの最小構成**：録音／読込、範囲選択、音量、フェード、手動の基準音、試奏を一通りつなぐ。
3. **保存と復元**：素材・編集設定・割り当てをCassetteに含め、再編集まで確認する。
4. **音程推定と周期波形編集**：候補表示、一周期抽出、手描き、Game Boyへの変換を加える。
5. **他modeへの展開**：PC98／NeoGeoのADPCM-Bで同じ操作を使い、必要に応じてADPCM-AやSNESへ広げる。

## 確認すること

- [x] 同じGuitar操作をFMとサンプラーへ渡せる。指板・音名・PCキーの割り当てが一致する。
- [x] 同音の複数押下、和音、ボイスの置き換え、画面外での解放、Stop／再Runで音が残らない。
- [x] 長めの録音から範囲を変更しても、元の素材へ戻れる。
- [x] 録音許可の待機中や録音中でもキャンセル・Stopでき、遅れて得た入力も解放する（生成MediaStreamで検証）。
- [x] 素材や範囲を変更した後、古い解析・変換の結果が新しい選択を上書きしない。
- [x] 音程が分かる単音、倍音の強い音、無音、ノイズで、推定と手動補正が適切に働く。
- [x] 容量、ループ、音程、ボイスの上限と消音、有限なPCM出力を実チップWASMで確認する。
- [x] Main／Worker、Chromium／WebKitで演奏・編集・保存を確認する。
- [ ] Tauri実機でマイクの権限表示、収録品質、編集しながらの演奏負荷を確認する。
- [x] Cassetteの保存・再読込後も、同じ素材を別mode向けに編集できる。

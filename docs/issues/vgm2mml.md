# VGM Analyzer：解析用MML出力

## 目的と位置づけ

VGM AnalyzerにMML出力を追加し、MMLに慣れたユーザーが曲の音程、発音間隔、
休符、音色変更を読み取れるようにする。

VGMはレジスター操作と待ち時間の記録であり、元の楽譜そのものではない。
出力は解析用の表現とし、元の楽譜の完全復元や再生の完全一致は目標にしない。
この文書は実装前の方針をまとめたもの。

## 決定した方針

- 機能の追加先はVGM Analyzer。
- BPMは手動指定、既定値は120。
- BPMは推定値ではなく、記録された時間をMMLの音長へ換算するための値。
- CHごとに音符・休符・音色変更を出力する。表示名はCH1から始める。
- 音長を丸める場合も、元のサンプル位置・長さをコメントに残す。
- ベンド、DACなど単純な音符に変換できない操作は注記する。

PMD、FMP、mucom88などへの互換出力は初期対応に含めない。
現時点では、それらの環境での動作確認を行う予定もないため、対応形式とは表示しない。
PlaygroundでのMML記法・再生のサポートは別途検討中であり、この機能の前提にしない。

## BPMと時間の扱い

待ち時間だけからBPMを一意に決めることはできない。
同じ発音間隔を異なるBPMと音長の組み合わせで表せるため、初期版では自動推定を行わない。

VGMの時間位置は44,100サンプル単位の整数値として保持する。
指定BPMから四分音符の長さを次のように求め、音長へ換算する。

```text
四分音符のサンプル数 = 44100 × 60 / BPM
四分音符単位の長さ = 区間のサンプル数 / 四分音符のサンプル数
```

BPM 120では四分音符が22,050サンプルになる。
BPMを変更しても、元データのサンプル位置や解析結果の時刻は変更しない。
有限の正数のみ受け付ける。UI上の範囲や小数入力の仕様は実装時に決める。

付点、タイ、細かい音長への量子化規則は未決定。
表記上の丸めを次の区間の時刻計算へ持ち越さず、累積誤差を防ぐ。
テンポ変化や拍子・小節境界の自動復元も初期対応に含めない。

## 解析と表現の案

まず元のイベント順と絶対サンプル位置を維持した中間データを作り、
MMLへの整形と音長の丸めは最後に行う。

- 音程はチップの周波数設定とクロック情報から求める。
  半音からのずれがある場合は、元の周波数設定やずれを注記する。
- KEY ON / KEY OFFから発音区間を抽出する。
  KEY OFFは操作時刻であり、リリースを含む実際の音の終了時刻とは区別する。
- 再KEY ONやオペレーター単位のKEY操作を、無条件に通常の単音へ置き換えない。
- 音色変更には解析用の音色IDを割り当て、元のパラメーターとの対応を残す。
  発音中のパラメーター変更は、必要に応じて時刻付き注記にする。
- ベンド、LFO、特殊モード、DACなどは、表現できないことを明示する。
  大量のDAC書き込みは範囲や件数で要約し、出力を読める量に保つ。
- ループは無限展開せず、元のループ開始位置を注記する。

対象チップの初期対応範囲、音色の同一性判定、コメント構文、
通常の音符として扱える条件は、既存Analyzerの解析結果を確認してから確定する。
未対応のCHや操作を黙って捨てず、出力内に警告・要約を残す。

## UI案

Analyzerに `Export MML` を追加する。
出力時にBPMを指定でき、初期値として120を表示する。
「解析用MML」「BPMは音長換算用であり自動推定ではない」ことを明記する。

ファイル名は読み込んだVGMの名前を基に `.mml` とする案。
出力ヘッダーには元ファイル名、指定BPM、対象チップ、解析用形式であること、
未対応要素の概要を記載する。コピー機能の要否は実装時に検討する。

## 確認項目

外部MMLドライバでの再生確認とは切り離し、解析・変換の正しさを確認する。

- BPM 120で22,050サンプルが四分音符へ換算される。
- BPMを変更しても元のサンプル位置・長さが保持される。
- 音符、休符、再発音、複数CH、同時刻イベントを適切に扱える。
- 音長の丸めによって後続イベントの位置がずれない。
- ベンド、DAC、特殊なKEY操作、ループの注記が残る。
- 未対応要素がある出力を、完全変換できたものとして表示しない。


## 初期実装

VGM AnalyzerにExport MMLとBPM入力欄を追加。BPMは既定120、UIでは1〜999の小数を許可。
初期対象はYM2612 FMのCH1〜CH6。YM2203/YM2608などの選択時は出力ボタンを無効にする。

解析記法は四分音符480tick、`o4 c%480` がMIDI 60の四分音符、`r%480` が休符。
区間の絶対開始・終了位置をそれぞれtickへ丸め、その差を音長にする。
非常に短い区間は0tickになり得るが、元のサンプル位置と長さは保持する。
`?%N` は音程を通常の音符として扱えない区間。

音程はヘッダーのYM2612クロックとBLOCK/FNUMから算出した基音であり、
音色のMULTI/DTや変調による知覚上の音高は復元しない。
音色IDは観測されたレジスター設定の対応表で、外部ドライバ向け音色定義ではない。
ベンドは区間分割とコメント、発音中の音色書き込みは時刻付きコメントにする。
DAC/PSG/未変換レジスターは件数と最初・最後のサンプル位置で要約する。
CH3特殊モードや部分KEY操作は不明音程として残す。
ループはヘッダーの位置・長さを注記し、展開しない。

itch.io向けパッケージにも変換モジュールを追加。
自動テストで音程・音長換算、休符、再発音、複数CH、注記、丸めの累積誤差を確認する。
外部MMLドライバでの再生互換性は未対応。

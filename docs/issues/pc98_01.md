# PC-98 FM Playground / MegaSynth 接続メモ

## 現状

- `YM2203Synth` / `YM2608Synth` を追加済み。
  - 共通実装: `web/opn_fm_synth.js`
  - YM2203: 3ch FM、mono、FM LFO/pan なし。
  - YM2608: 6ch FM、2 port、FM LFO/pan あり。
- 各 Synth は `setOperator()`、`setAlgo()`、`setFrequency()`、key on/off、
  raw write、Channel 3 special mode を持つ。
- register sequence と WASM address/data bus のテストを追加済み。
- `ym2203-worklet.js` / `ym2608-worklet.js` は追加済みだが、まだ
  `MegaSynth` / Playground から起動されない。
- YM2203/YM2608 VGM の FM-only を YM2612 向けへ変換する既存 import は維持する。

## 基本方針

PC-98 chip と YM2612 は同時ミックスしない。

```js
setSoundChip("ym2608");

// `fm` は選択 chip の FM API を指す。
fm.setFrequency(CH1, 4, 553);
fm.keyOn(CH1);
```

- `setSoundChip("ym2612" | "ym2203" | "ym2608")` は source 冒頭の起動前宣言にする。
- Run 中の chip 切替は許可しない。
- `ym2612` を選択しなければ DAC と Mega Drive Sega PSG は公開しない。
- `fm` は選択 chip の共通 FM API。必要なら `fm2612` / `fm2203` / `fm2608` を
  明示 namespace として後から追加する。

## 共通 Audio Runtime の分離を先行する

PC-98 Synth を追加する前に、現在の `MegaSynth` から chip 非依存機能を分離する。

`extends SynthBase` ではなく composition を採用する。`MegaSynth` 自体は
共通 runtime ではなく、YM2612 / Sega PSG / DAC を持つ chip Synth だからである。

```js
class MegaSynth {
  constructor(options) {
    this.audio = new TetoricaAudioRuntime(options);
  }
}

class PC98Synth26 {
  constructor(options) {
    this.audio = new TetoricaAudioRuntime(options);
  }
}

class PC98Synth86 {
  constructor(options) {
    this.audio = new TetoricaAudioRuntime(options);
  }
}
```

### TetoricaAudioRuntime の担当

- AudioContext と master gain / output routing。
- FX chain。
- noise generator。
- sample / stream。
- volume。
- AudioNode の接続・破棄。
- Playground Main thread 側の audio handle 管理。

### Chip Synth の担当

- chip 固有 Worklet と WASM の起動。
- `fm` API と register write。
- chip output node を `audio` runtime の入力へ接続すること。
- chip 固有機能。
  - MegaSynth: YM2612、Sega PSG、DAC、YM2612 command recorder。
  - PC98Synth26: YM2203。将来 SSG。
  - PC98Synth86: YM2608。将来 SSG、Rhythm、ADPCM-B。

### 移行順

1. `TetoricaAudioRuntime` を追加し、MegaSynth の chip 非依存機能を移す。
2. MegaSynth の既存 API は forwarding で維持する。
3. YM2612 Worklet、Sega PSG、DAC、YM2612 command recorder は MegaSynth に残す。
4. Playground の Main / Worker で FX、noise、sample、stream、DAC、record/looper の回帰を確認する。
5. 検証後に PC98Synth26 / PC98Synth86 を同じ runtime へ接続する。

## 接続時に決めること

### Chip Synth / MegaSynth

- 選択 chip の Worklet node を一つだけ生成して、`TetoricaAudioRuntime` の入力へ接続する。
- `ym2612-worklet.js`、`ym2203-worklet.js`、`ym2608-worklet.js` は分けたまま維持する。
- YM2203/YM2608 は chip native sample rate で PCM を作り、AudioWorklet output rate へ
  box-average で変換する。これは既存 `Ym2203AudioEngine` / `Ym2608AudioEngine` と同じ方式。
- YM2612 command recorder は MegaSynth 固有として残す。PC-98 用 recorder は後から chip 別に検証する。

### Playground

- Main thread と Worker の globals、Monaco completion、
  `tetorica-playground-globals.d.ts` を同時に更新する。
- Worker は chip を切り替えない。Main thread が選んだ chip に対する FM command だけを送る。
- Stop は key off/reset、FX detach、prepared context の破棄まで行う。
- 同じ chip の連続 Run は node/context を再利用する。chip が変わる Run だけ node を作り直す。

### VGM Import

- `FM to YM2612`: 現在の互換変換を残す。clock 差の FNUM 変換と YM2612 pan 補完を行う。
- `Native YM2203/YM2608`: `setSoundChip()` を先頭に出力し、VGM の対象 chip write を
  native chip へ流す。FM 以外の register は対応機能を公開するまで除外または注記する。

## PC-98 固有機能の段階

1. YM2203/YM2608 の FM のみ。
2. YM2203/YM2608 内蔵 SSG。
3. YM2608 Rhythm。
4. YM2608 ADPCM-B と ROM/サンプル読み込み。

## 品質保証

- 既存の high-level API register sequence test を維持する。
- chip ごとに単音、key on/off、Channel 3 special mode の PCM fixture を追加する。
- YM2608 は LFO/pan の PCM fixture も追加する。
- Browser で Main / Worker の Run -> Stop -> Run、FX、record/looper を確認する。
- native VGM import と YM2612 互換 import の両方を確認する。

# VGM Analyzer TODO：Sample Explorerの対応拡張

更新日：2026-09-29。Sega PCM・OKIM6258は初回実装済み。ほかの音源は計画・未着手。
全体の対応状況は[機能一覧](../feature-status.md)、音源別の再生対応は[Sound chip support](../vgm_analyzer/support.html)を参照。

## 目的

PCM／ADPCMを再生できても、Sample Explorerでデータ・使用履歴を調べられない音源がある。
再生対応とサンプル解析対応を分けて管理し、一覧・抽出・波形表示・試聴の対象を拡張する。

## 現在の対応範囲

| 音源・機能 | 解析するデータ | 主な制限 |
|---|---|---|
| YM2610／YM2610B ADPCM-A/B | 埋め込みROM内の範囲と使用イベント | データ不足やADPCM-Bのアドレス折り返し等に制限あり |
| YM2608 ADPCM-B | 外部メモリーの範囲と使用イベント | CPU供給型再生・録音・一部の折り返しは対象外。リズムは別 |
| RF5C164 | 64 KiB RAMスナップショット、開始・ループ位置 | 元の音色ファイルを復元するものではない |
| YM2612 DAC | 時刻付き出力キャプチャ | 音色境界の完全復元ではない |
| 32X PWM | 時刻付き左右出力キャプチャ | 音色境界の完全復元ではない |
| OKIM6258 | play／stop区間の時刻付きADPCMレジスタキャプチャ | 単体／YM2151併用。JSON／ZIP・波形・最大10秒の試聴／WAV。開始前の分周位相は再現しない |
| Sega PCM | 発音開始時点のunsigned 8-bit ROM範囲、バンク・ループ・使用イベント | 単体／PSG／YM2151併用。試聴は左右音量を保持する1回再生。折り返し範囲・live変更の再現は未対応 |
| YMF278B PCM | キーオン時のサンプル・設定、波形、試聴／WAV | 必要なWave ROMは別途読み込む。演奏全体の完全再現ではない |

実装の入口：[sample_core.js](../vgm_analyzer/sample_core.js)、
[Sample Explorer UI](../vgm_analyzer/sample_explorer.js)、[試聴処理](../vgm_analyzer/sample_render.js)。
CLIの一覧・native抽出・WAVも共有処理を使うが、ROM受け渡し等の入口は別途確認する。

## 未対応：PCM／ADPCM系

| 優先 | 音源・機能 | 追加したい内容 | 設計上の注意 |
|---|---|---|---|
| 3 | YM2608リズム | 読み込んだリズムROMの6打楽器、波形・試聴、使用履歴 | ADPCM-Bとは別機能。Tetorica製ROMと利用者指定ROMの両方を扱い、差し替えで解析結果を無効化 |
| 後続 | Y8950 ADPCM | サンプルメモリー、再生範囲・使用履歴、抽出・試聴 | 単体／MSX併用を確認。メモリー型とCPU供給型の対応範囲を明示 |
| 後続 | NES DMC | DPCMデータ、開始アドレス・長さ・レート・ループ設定 | 読み出しメモリーと更新履歴を追跡。直接DAC書き込みのキャプチャは別範囲として判断 |
| 後続 | HuC6280 DDA | 時刻付きPCM出力キャプチャ、波形・試聴 | YM2612 DACに近い方式。CH別に追跡し、波形モードとの切り替えを扱う |

OPN／OPM中心のアプリとして、まず **Sega PCM → OKIM6258 → YM2608リズム** の順を候補とする。
Sega PCM・OKIM6258は下記の範囲で初回対応済み。次はYM2608リズムを候補とする。両者の対応により、YM2151併用曲のPCM／ADPCM部分を調べられるようにする。

## 別枠：波形メモリーの表示・保存

長いPCMサンプルの抽出とは分け、書き換え時点の波形スナップショットとして検討する。

- [ ] Game Boy CH3：波形RAMと使用設定。
- [ ] HuC6280：各CHの波形メモリー。DDAキャプチャとは区別。
- [ ] K051649／K052539（SCC／SCC+）：波形メモリーと更新履歴。
- [ ] FDS：波形RAM。変調設定を含める範囲は別途設計。

## 共通の実装・受け入れ項目

- [ ] サンプル定義と使用イベントを分離し、同じデータの複数回使用を一覧化する。
- [ ] 使用時点のメモリーを保存し、後の上書きで過去の波形が変わらないようにする。
- [ ] データ不足・部分抽出・区間推定を明示する。空一覧を「PCMなし」と断定しない。
- [ ] rawデータ／時刻付きキャプチャ／波形スナップショットを表示と保存形式で区別する。
- [ ] 波形表示・native保存・使用回選択による試聴／WAVの対応範囲を決める。
- [ ] 単体と併用構成でSamplesタブを利用可能にする。抽出コアだけで完了にしない。
- [ ] CLI `samples` の一覧・単体／一括抽出・WAVへ共有処理を接続する。
- [ ] 読み込み済みROMを渡し、ROM差し替え・曲切り替えで結果と試聴を破棄する。
- [ ] 自作fixtureでメモリー変更、ループ、停止／再開、バンク切り替え、欠損データを検証する。
- [ ] 長い曲のメモリー／イベント上限、キャンセル、試聴停止を検証する。
- [ ] ブラウザーで一覧・保存・試聴を確認し、環境と結果を記録する。
- [ ] Sound chip supportの原本と生成ページ、機能一覧、CLI仕様を更新する。

実装時には音源ごとに上記の適用範囲を確定する。Sample Explorer対応は、
PCM／ADPCMの採譜や原曲の音色境界・基準音高の完全復元を意味しない。


## Sega PCM初回実装（2026-09-29）

- `segapcm_samples.js`で16CHのレジスタ、ROM世代、バンク、再生位置・ループ・停止を追跡。
  同じROM世代・範囲は定義を共有し、使用回ごとの速度・左右音量・開始／終了をイベントに保存する。
- 分割ロード、ROM上書き・縮小を反映。後からロードしたデータで過去の欠損を補完しない。
- Sample Explorer：波形、バンク／開始／ループ位置、使用履歴、raw PCM保存、使用回選択、ステレオ試聴、WAV保存。
- 単体・Sega PSG併用・YM2151併用でSamplesタブを利用可能にし、選択中のタブを維持する。
- CLI共有処理：`samples --json`、native単体／ZIP、`--format wav`に接続。
  rawデータはunsigned 8-bitの`.bin`。配置・ループ情報は一覧／ZIP manifestに保持する。
- 試聴は最大10秒、発音時点の設定で開始アドレスから終端まで1回再生。
  ループ前の領域も抽出に含めるが、試聴ではループせず、実コアを使って左右音量・速度を適用する。
- ROM／設定のlive変更は警告し、イベントの`changes`にレジスタ変更を保存。試聴では追従しない。
- アドレス折り返し・終端ページを開始／ループに指定する特殊範囲、欠損ROMは抽出不可として明示。
  第2チップは未対応。音色境界の復元や採譜には対応しない。
- 保存PCMは64 MiB、定義／イベント／live変更件数はそれぞれ上限を設ける。
  既存の解析キャンセル・試聴停止と統合する。

バンク既定値・マスク制限、ROM世代／欠損／縮小、ループ・自然停止・再発音、
範囲外書き込み、抽出・ZIP・WAV、実コアとの左右PCM一致、UIのタブ・波形・保存・試聴停止、実CLIの一覧／native／ZIP／WAVコマンドを確認。
UI確認はDOM／AudioContextモックによる自動テスト。実ブラウザーでの実曲試聴は未実施。

itch.io用パッケージに新モジュールを追加し、検証用ZIPの生成・依存検証に成功。公開は未実施。

## OKIM6258初回実装（2026-09-29）

- `oki6258_samples.js`：単一チップの4-bit ADPCMを対象に、play／stopの区間と
  データ供給・パン・クロック／分周書き込みを順序・時刻付きで保存する。
  VGMの直接書き込みとストリーム経由の供給は同じ入口で処理し、二重取得しない。
- 同じ再生中のplay再指定は区切らず、stop／録音コマンド／VGM終端で閉じる。
  曲ループは展開しない。区間は原音色の境界と同義ではない。
- 初期の確定クロック、未確定のクロック書き込みバッファ、分周、パンを保存する。
  第2チップ、dual／variant、3-bit、録音は対象外として警告する。
- Samplesタブ：単体とYM2151併用で有効化。再生履歴・ADPCMバイト数を表示し、
  デコード波形表示、時刻付きJSON保存、ステレオ試聴、WAV保存を提供する。
- CLI：`samples --json`、native単体／ZIP、`--format wav`に共有処理を接続。
  `representation`は`timed-adpcm`。データバイトだけを`.bin`保存すると供給時刻が失われるため、
  native形式は`tetorica-okim6258-capture`（schemaVersion 1）のJSON。
  使用時刻・初期設定・`times`／`registers`／`values`を含む。JSONの再インポート機能は未実装。
- 波形・試聴・WAVは既存WASMデコーダーで先頭最大10秒を生成する。
  パン／クロック／分周の途中変更も再現し、native JSONは区間全体を保存する。
  解析には全体100万書き込み・10万区間の上限を設け、既存キャンセル／試聴停止と統合。

制限：キャプチャ開始時に分周位相を初期化する。開始前の無音期間中の位相は保存しないため、
曲途中のキャプチャは全曲再生とサンプル単位で一致する保証はない。
FIFOのあふれ・データ不足時の挙動は既存コアに従い、元の音色境界や楽譜は復元しない。

`oki6258_samples.test.mjs`の10テストが成功。
直接／ストリーム供給、同時刻順序、停止／再開、途中のクロック・分周・パン、
実コアとのPCM一致（開始時刻0）、未確定クロックバッファ、未対応形式、キャンセル、
10秒上限、UIのタブ・波形・保存・試聴停止、実CLIの一覧／JSON／ZIP／WAVを確認。
UIはDOM／AudioContextモックによる自動確認。実ブラウザーでの試聴・公開は未実施。

配布スクリプトに新モジュールを追加。Sound chip support、CLI仕様、機能一覧も更新済み。

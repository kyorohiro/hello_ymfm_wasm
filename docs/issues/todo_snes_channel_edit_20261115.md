# SPC physical CH editing — 2026-11-15

Edits use current DSP bytes, preserve packed neighbors, CPU RAM, transport position, other channels and current envelope phase, and return an atomic post-write snapshot. PITCH zero and unsupported sample snapshots remain editable without requiring a portable preset. Paused audition updates preserve held notes when the sample layout remains compatible.

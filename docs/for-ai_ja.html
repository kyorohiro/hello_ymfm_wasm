Tetorica Playground — AI向けガイド

English | 日本語

Tetoricaのブラウザー版Playground用のJavaScriptを生成するときは、以下の型定義と動作するサンプルを参照してください。

型定義

  • Playground共通API
  • YM2612 / メガドライブ用
  • YM2608 / PC-98用
  • YM2203 / PC-98用
  • YM2610 / Neo Geo用

共通APIと、対象のPlaygroundで選択するチップの型定義を読んでください。

動作するサンプル

サンプルの正本はplayground_examples.jsです。以下のリンクはPlaygroundで利用する代表的なサンプルです。読み込んでも自動では実行されません。

  • PlaygroundのFILES → examplesからソースを開いて実行してください。
  • Live Loop— テンポ、音符、名前付きループ
  • Ambient Choir Sample— サンプルの読み込み、FX、実行中の状態
  • Noise Ocean— ノイズの生成とパラメーター操作
  • FM API Beep— YM2612の直接設定
  • PSG Scale— SN76489互換のトーンAPI
  • Parallel FX— 分岐したエフェクト経路

実行時のルール

  • TypeScriptではなくJavaScriptを生成してください。
  • トップレベルのawaitに対応しています。
  • PlaygroundのAPIは、グローバル変数としてもpg経由でも利用できます。
  • 独立したliveLoop()とlivePrepare()の状態には、安定した一意の名前を使ってください。
  • プロジェクトのファイルはfile()で読みます。相対パスは実行するファイルを基準に解決します。
  • ユーザーコードの実行中は、ネットワークAPIや外部パッケージのインストールを利用できません。

プロンプトに添える情報

Tetorica Playgroundで動くJavaScriptを書いてください。
リンク先の共通APIと選択チップの.d.tsで宣言されたAPIだけを使ってください。
動作する公式サンプルに従ってください。
Playgroundへ貼り付けてそのまま実行できるJavaScriptを返してください。

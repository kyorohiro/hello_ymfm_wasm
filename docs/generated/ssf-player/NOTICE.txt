Its source is tetorica_src/wasm/ssf_player/ssf_player.cpp.
Rebuild with node scripts/build_ssf_player.mjs using Emscripten and CMake.
ABI 4 adds a passive, same-frame read-only DSP observer: all 128 raw
instructions, 64 signed coefficients, 32 memory addresses and 16 raw effect
outputs. TEMP/MEMS and DSP editing are not exposed. The original slot/RAM
snapshot ABI is unchanged. ABI 3 includes a passive slot/RAM observer and bounded, masked host edits
for individual voices' Envelope, LFO and Mix registers. Host edits do not
advance the CPU, restart voices or change RAM; the song driver can overwrite
them later. The build creates temporary
copies from pinned sources and includes the readable ssf_observer.inc.
The source kit retains these inputs and the build recipe.

Working examples

The canonical example source is playground_examples.js. The following links load representative examples into the Playground. Loading an example does not run it automatically.

  • Live Loop — tempo, notes, and named loops

  • PSG Scale — SN76489-compatible tone API
  • Parallel FX — branched effect routing

Execution contract

  • Generate JavaScript, not TypeScript.
  • Top-level await is supported.
  • Playground APIs are available as globals and through pg.
  • Use stable, unique names for independent liveLoop() and livePrepare() state.
  • Project files are read with file(); relative paths resolve from the running file.
  • Network APIs and external package installation are unavailable during user-code execution.

Suggested prompt context

You are writing JavaScript for the Tetorica Playground.
Use only APIs declared in the linked common and selected-chip .d.ts files.
Follow the canonical working examples.
Return JavaScript that can be pasted into the Playground and run directly.

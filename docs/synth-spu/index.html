    Use const ps1 = await useSoundChip("ps1") and await its methods. Code addresses physical channels 0–23; CH1 is 0. It uses the loaded PCM, Audio or VAB Tone. PMON retains its paired physical voices: CH2 is the first carrier. Run starts fresh; Apply keeps context and named preparations. Stop fades the output and restores your edited instrument and sample bank.
    Click guard is a software feature, On by default for keyboard and noteOn / noteOff. It smooths transitions within each voice and gives very fast releases a minimum of about 3 ms without changing ADSR codes or shortening longer releases. Changing it affects subsequent gate operations. For raw KON/KOFF use setNote + keyOn and keyOff; these always bypass the guard and still follow the programmed ADSR.
    Code changes do not overwrite saved instruments. Live displays the selected channel in the same PCM / ADSR / FX controls. Live Off returns to editing; changing an instrument or loading a sample stops Code. Scheduling and liveFx are software features; SPU reverb remains the chip's shared effect.

LP keeps lower frequencies; BP keeps a band; HP keeps higher frequencies. Notch combines LP + HP. One filter is shared by the playing voices.

Voice 3 → Voice 1

SYNC / RING

Sync resets Voice 1's oscillator from Voice 3. Ring affects Triangle. The modulator is silent; using it reserves Voice 3 and disables the triad.

SID clock

Changing the clock stops the test; play again to use it. Wave, ADSR, pulse width, filter, Sync and Ring control SID registers. Test tones, the triad, output level and this display are lab software.

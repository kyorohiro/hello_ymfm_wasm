## Sonic Pi Samples For Playground

This directory is for sample files used by the Tetorica playground.

The current plan is to place CC0 sample assets from Sonic Pi here when they
are useful for comparison, prototyping, or playback tests such as
`sample.load(...)` and `stream.load(...)`.

Example intended source:

- `ambi_choir.flac`
  - source repository:
    [sonic-pi-net/sonic-pi](https://github.com/sonic-pi-net/sonic-pi)
  - original path:
    [`etc/samples/ambi_choir.flac`](https://github.com/sonic-pi-net/sonic-pi/blob/stable/etc/samples/ambi_choir.flac)

License notes:

- Sonic Pi's bundled files under `etc/samples/` are described in
  [`LICENSE.md`](https://github.com/sonic-pi-net/sonic-pi/blob/stable/LICENSE.md)
  and
  [`etc/samples/README.md`](https://github.com/sonic-pi-net/sonic-pi/blob/stable/etc/samples/README.md)
- Those sample assets are documented there as CC0 1.0

This directory is only for the sample assets themselves and their source /
license notes. It does not change the license of the surrounding Tetorica
project code.

pg

            
    
              
  • pg is the main playground helper namespace
    • 
              
  • pg.play("C4", { channel: 0, duration: 0.2 }) plays one note
    • 
              
  • pg.sleep(0.25) waits in seconds
    • 
              
  • pg.liveLoop("bass", async () => {}) keeps a named loop alive
    • 
              
  • pg.setBpm(120), await pg.beat(1), await pg.nextBeat()
    • 
              
  • await pg.livePrepare("main-fx", async ({ fx }) => ...) reuses prepared live state across runs
    • 
              
  • pg.scale("Eb2", "majorPentatonic", 2) builds note arrays
    • 
              
  • pg.choose(array), pg.rand(), pg.randInt(0, 7)
    • 
              
  • pg.stopLoop(name), pg.stopAllLoops(), pg.stopAll()
    • 
            


            
fm

            
    
              
  • fm is the raw YM2612Synth layer
    • 
              
  • await play("C4") plays one note
    • 
              
  • pg.fm points to the same YM2612 layer
    • 
              
  • fm.setPreset(0, pg.presets["one-op-basic"]) applies one preset
    • 
              
  • fm.write(port, register, value) sends one YM2612 register write
    • 
              
  • fm.writeAddress(port, register), fm.writeData(value) follow the YM2612 address/data flow
    • 
            


            
fx

            
    
              
  • fx is the master FX helper layer
    • 
              
  • pg.fx points to the same FX helper layer
    • 
              
  • fx.eq(...), fx.filter(...), fx.delay(...), fx.reverb(...)
    • 
              
  • fx.setChain([filter, delay]) replaces the master FX chain
    • 
              
  • eq.bass.set(...), eq.mid.rampTo(...), eq.treble.set(...)
    • 
              
  • filter.cutoff.set(...), filter.cutoff.rampTo(...)
    •

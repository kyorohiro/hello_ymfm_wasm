YM2612 基本メモ

このページは、この repository にある初期メモをブラウザで読みやすくしたものです。 まずは「pin と register を見ながら beep まで辿る」ことを目的にしています。

何を見るページか

  • YM2612 の pin の意味
  • A0 / A1 と chip.write() の対応
  • beep を鳴らすときに触る最小レジスタ群
  • ex03_beep.cpp を読むための入口

ざっくりした全体像

  1. ym2612 オブジェクトを作る
  2. reset() する
  3. channel 1 の operator を設定する
  4. algorithm と左右出力を設定する
  5. 周波数を設定する
  6. Key ON する
  7. サンプルを生成する

重要な register group

  • 0x30-0x3c: detune / multiple
  • 0x40-0x4c: total level
  • 0x50-0x5c: attack rate
  • 0x80-0x8c: sustain level / release rate
  • 0xb0: algorithm / feedback
  • 0xb4: 左右出力
  • 0xa4 と 0xa0: 周波数
  • 0x28: key on / key off

chip.write() の見方

chip.write(0, 0x30);
chip.write(1, 0x01);

これは「address port 0 で 0x30 を選び、data port 0 から 0x01 を書く」 という意味です。

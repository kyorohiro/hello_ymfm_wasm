VGM Runtime Embedded Demo

This example wraps the current YM2612 + PSG VGM playback path in one small runtime API. 

import {
  VgmRuntime,
} from "../js/vgm_runtime.js";

const vgm =
  VgmRuntime({
    audioWorkletUrl:
      "../js/vgm-output-worklet.js",
  });

await vgm.initialize();
await vgm.load(vgmArrayBuffer);
await vgm.play();

Import. Play. Build.

tetorica-fm2612 を自分のアプリで使うための、小さな JavaScript サンプル。
コードを読んで、実行して、そのまま持ち帰れます。

npm install tetorica-fm2612

このページは import map で npm パッケージの ES modules を CDN から読み込みます。初回はネット接続が必要です。音は Run を押すと再生されます。

自分のプロジェクトで使う

サンプルは run() を export しています。ブラウザではボタンの click から呼び出してください。run({signal}) に AbortSignal を渡すと再生を停止できます。

import {run} from './note.js';
document.querySelector('button').addEventListener('click', () => run());

静的サイトではパッケージの中身を /vendor/tetorica-fm2612/ にコピーして、次の import map を module script より前に置きます。JS・WASM・Worklet のディレクトリ構成を保ってください。

<script type="importmap">
{"imports": {
  "tetorica-fm2612": "/vendor/tetorica-fm2612/soundchip.js",
  "tetorica-fm2612/": "/vendor/tetorica-fm2612/"
}}
</script>

ブラウザでは import map のサブパスに .js を付けます。npm を使う Node.js ではこのコードの import をそのまま解決できます。PCM → WAV の例は Node.js 22 以降でも実行できます。

import {writeFile} from 'node:fs/promises';
import {run} from './wav.js';
const wav = await run();
await writeFile('example.wav', new Uint8Array(await wav.arrayBuffer()));

バンドラーを使う場合も WASM・Worker・Worklet を配布する必要があります。詳しい設定は package README を参照してください。

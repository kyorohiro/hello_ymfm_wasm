Tetorica FM2612 (hello_ymfm_wasm)

English | 日本語 | AI/SI

Tetoricaは、JavaScriptでメガドライブやゲームボーイなどのレトロゲームサウンドをライブコーディングするツールです。

プロジェクトの目標

このリポジトリーには4つの目標があります。

  • YM2612チップを理解すること。
  • 誰でもYM2612チップを理解できるドキュメントを作ること。
  • ブラウザーアプリやゲームにYM2612の音声を組み込む方法を、誰でも理解できるドキュメントを作ること。
  • 古いゲーム音楽や音源チップの技術を文化的な遺産として残すこと。保存・再生に加え、今の人たちが読み解き、調査し、学び、再構成できる形を目指します。

このリポジトリーでは、ブラウザーで使うYM2612のWebAssemblyモジュールとJavaScriptインターフェースも提供しています。

リポジトリー： https://github.com/kyorohiro/hello_ymfm_wasm

これらのデモは ymfm （Aaron Giles、BSD 3-Clause License）を使っています。

npmパッケージ

自分のプロジェクトでもTetoricaを使えます。tetorica-vgmでVGM音楽を解析し、tetorica-fm2612で音源チップの音声を生成できます。Node.jsでの利用にはNode.js 22以降が必要です。

VGM解析 · Node.js CLI / API

tetorica-vgm

VGM / VGZファイルの解析、楽譜・FM音色のエクスポート、WAV生成を行います。コマンドラインから使うほか、解析・エクスポートAPIをNode.jsアプリに組み込めます。 

npm install tetorica-vgm
npx tetorica-vgm analyze song.vgz --json
npm → 使い方・Node API → CLIリファレンス →

音源チップ · ブラウザー / Node.js

tetorica-fm2612

ビルド済みWASMとともに、音源コア・Synth APIをESモジュールとして読み込めます。Node.jsでPCMを生成したり、同梱のWeb AudioランタイムでブラウザーアプリにFM・PSG・PCMの音声を組み込めます。 

npm install tetorica-fm2612

YM2612や関連するYamaha音源、Sega PSG、RF5C164などを収録しています。createSoundChip、YM2612Synth、MegaSynthから試せます。

npm → Web・Node.jsの実行例 →

入門

JavaScriptで学ぶメガドライブのYM2612 FM音源 FM合成とYM2612のオペレーター・アルゴリズムの働きを、ページ内のPlaygroundで実際に試しながら学べます。
JavaScriptで学ぶメガドライブのSega PSG 矩形波・3音の和音・ノイズを、編集できるJavaScriptで聴き比べます。
JavaScriptで学ぶメガCDのRF5C164 自作波形をRAMから再生し、読む速さ・音量・左右出力を変えてPCM音源の基本を試します。
JavaScriptとメガドライブのYM2612で聴く純正律と平均律 1つの周波数から単純な比率で音程を作り、純正律と平均律の違いをYM2612で直接聴き比べます。
音源チップからビープ音まで：JavaScriptで扱うYM2612 レジスターでYM2612を操作する仕組みを学び、埋め込まれたPlaygroundでビープ音のコードを編集・実行します。
JavaScriptで学ぶFX — 作成中 GainからReverb、エフェクトチェーンまで、作成中の15のFXレッスンを編集可能なPlaygroundの例で試せます。
Game Boy 01 — Pulse：パルス波を聴き比べる デューティ比・音程・音量を変え、実際の音とPCM波形を比較。設定をJavaScriptで持ち帰れます。 Game Boy 02 — Envelope：発音後の音量を変える 初期音量・増減方向・周期を操作し、音量の時間変化を聴いて、生成PCMの振幅から確かめます。 Game Boy 03 — Wave：32点の波形を描いて鳴らす 波形を編集して三角波やノコギリ波を比較。配列のコピー・貼り付けとPlaygroundでの編集にも対応。

Webアプリやゲームに音源チップを組み込む

小さな実行例を通じて、tetorica-fm2612 npmパッケージの使い方を学べます。チップの直接操作、AudioWorklet出力、FX付きMegaSynth、イベントの記録とループ、Playgroundの組み込み、VGM再生、TFI / VGI音色を試せます。

tetorica-fm2612の実行例 ブラウザーデモを動かし、Web・Node.jsのソース全体を読んで、ランタイムの構成を確認できます。

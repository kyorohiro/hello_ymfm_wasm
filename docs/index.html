Tetorica FM2612 (hello_ymfm_wasm)

English | 日本語 | AI/SI

Tetorica is a tool for live coding retro game sounds in JavaScript, including the sounds of the Sega Genesis / Mega Drive and Game Boy.

Goals

This repository has four goals:

  • To understand the YM2612 chip.
  • To create documentation that helps anyone understand the YM2612 chip.
  • To create documentation that helps anyone embed YM2612 audio in a browser app or game.
  • To preserve older game music and sound chip technology as cultural heritage that people today can read, investigate, learn from, and reconstruct—not only archive and play back.

This repository also provides YM2612 WebAssembly modules and JavaScript interfaces for browser-side use.

Repository: https://github.com/kyorohiro/hello_ymfm_wasm

npm Packages

Use Tetorica in your own projects: analyze existing VGM music with tetorica-vgm, or build sound-chip audio with tetorica-fm2612. Node.js usage requires Node.js 22 or later.

VGM tools · Node.js CLI / API

tetorica-vgm

Analyze VGM/VGZ files, export scores and FM voices, and render WAV audio. Use the command line or import the analysis and export APIs into a Node.js application. 

npm install tetorica-vgm
npx tetorica-vgm analyze song.vgz --json
npm → Usage & Node API → CLI reference →

Sound-chip audio · Browser / Node.js

tetorica-fm2612

Import sound-chip cores and synth APIs as ES modules with prebuilt WASM. Generate PCM in Node.js, or add FM, PSG and PCM audio to a browser app with the included Web Audio runtime. 

npm install tetorica-fm2612

Includes YM2612, related Yamaha chips, Sega PSG, RF5C164 and other sound chips. Start with createSoundChip, YM2612Synth or MegaSynth.

Native C++ / WASM Sources

Reusable sound-chip sources · C/C++ / WebAssembly

tetorica-soundchip-native

Build sound-chip audio into your own application with C/C++ cores, native adapter sources and WebAssembly build recipes collected in one repository. Component licenses, source provenance and local modifications are documented alongside the code.

The standalone native build currently supports YM2612 (ymfm). Other chip adapters are included as reference sources, with their build requirements and backend differences documented.

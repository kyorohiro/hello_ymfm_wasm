  • S98: one YM2203, YM2608 or YM2612 device. Compressed S98 and multiple devices are not supported.
  • MSX mix: Y8950 + AY + YM2413 + K051649 (SCC) playback and per-chip/channel controls. Analysis of the mixed configuration is not yet available. A second K051649 instance is not supported.
  • Sample memory: some YMF278B tracks need an imported yrw801.rom (2 MiB). YM2608 rhythm playback uses the ADPCM-A ROM. YM2610 ADPCM uses the VGM's embedded ROM data. OKIM6258 needs no external sample ROM.
  • OKIM6258: 3-bit ADPCM, recording and a second instance are not supported. YM2151 mixing is covered by synthetic tests with real cores.
  • Sega PCM: an arcade chip (OutRun, Space Harrier, System 16/18/24, ...), not a stock Genesis/Mega Drive cartridge chip. ROM bank shift/mask come from the VGM header's interface register. Mixes with Sega PSG and/or YM2151 (e.g. OutRun). A second instance is not supported.
  • Game Boy DMG: not mixed with any other chip yet. The DMG wave-RAM corruption glitch (retriggering channel 3 at an exact bad moment) is not reproduced. Note-ish/MIDI/LilyPond are write-driven approximations: length-counter timeout and channel 1 frequency sweep are time-based and not reconstructed from register writes.
  • Note-ish / MIDI / MML: estimated base pitches and key intervals; PCM/drums and all modulation are not transcribed. MML uses a sixteenth-note grid. OPN exports target MUCOM88 / OPNAvoid; YM2151 targets MXDRV (MDX).
  • DAC streams: first-instance YM2612, Sega PSG, PWM and OKIM6258 destinations are supported. Other destinations are warned about and omitted.
  • All / Snapshot: All collects voices across the track; Snapshot captures the current channel states. Unsupported chips and features can leave parts of a track silent; check the playback warning area.

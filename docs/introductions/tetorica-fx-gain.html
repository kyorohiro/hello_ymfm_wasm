FX INTRODUCTION / 01

Gain：音の波形に掛け算する

音色を変える前に、音の大きさを変えてみましょう。最初のエフェクトは、PCMの数値に1つの値を掛けるだけです。

この章では、Gainの倍率、波形との関係、そして自分で書くliveFxの基本を扱います。

1. まず聴いてみる

220 Hzを狙ったYM2612のサイン波を、4拍鳴らして1拍休みます。チップの周波数設定には量子化があるので、厳密な220 Hzとは限りません。

volume.gain.set(0.5)の値を変えて比較します。0は無音、1はこのFXでは振幅を変えない設定です。

iframe内のRunで再生し、Stopで停止します。再生中に値を編集したらApplyで反映してください。比較する前に、もう一方のPlaygroundをStopしてください。それぞれ独立した音声環境です。

RunしたらFX Monitorでnoneを選ぶと、組み込みFXを通った後の波形が見られます。liveFx("none", …)は観測用の素通し処理です。青とオレンジは同じ波形で重なり、組み込みFXの加工前後の比較ではありません。設定を変更してApplyし、波形の変化を見てください。

このコードを別タブのPlaygroundで開く ↗

2. 何を掛けているのか

PCMは、時間に沿って並んだ波形の値です。正負の値は波形の向きで、音の高さを直接表す値ではありません。Gainは各値を同じ倍率で伸縮します。

output = input × gain

入力Gain出力
0.20.50.1
−0.20.5−0.1
0.200

0.5倍にすると振幅は半分ですが、聴感上「半分の大きさ」とは限りません。振幅比をdBで書くと 20 × log10(gain) なので、0.5倍は約−6.02 dBです。0倍は対数で表せる有限値を持ちません。

波形を潰さず同じ倍率を掛けるだけなら、新しい倍音は作りません。過大な出力をクリップさせると、単純なGainとは違う加工になります。

3. 同じ掛け算をliveFxで書く

入力と出力は左右のチャンネルごとの配列です。chはYM2612の物理CHではありません。iは、今回届いた短い音声ブロック内の位置です。

output[ch][i] = input[ch][i] * context.gain;

contextは音声処理へ渡す設定、stateは次回へ残す履歴です。Gainは過去の音を使わないため、stateは空のままで構いません。

このコードを別タブのPlaygroundで開く ↗

  1. Runして、FX Monitorでgain-labを選びます。
  2. 青が入力、オレンジが出力です。Gain 0.5では、出力の波形の高さが半分になります。
  3. Codeへ戻り、contextのgainを1に変えてApply。Monitorでは波形が重なります。
  4. 0.25、0も試します。Spectrumのピークの位置は保たれ、強さが変わります。

表示は短い区間の切り出しなので、フレームごとに波形が横へ動く場合があります。入力と出力の同じ時刻を比較してください。

組み込みGainはパラメーター変更を滑らかにする処理も持ちます。この最小例は値を即座に変えるので、変更時にクリック音が出る場合があります。liveFxの出力は現在−1〜1に制限されます。

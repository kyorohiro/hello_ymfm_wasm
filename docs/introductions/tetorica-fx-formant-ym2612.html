YM2612 formants: make an FM tone speak

English | 日本語

Use the YM2612 as a harmonic-rich source, then shape it with the same liveFx formant filter. Compare chip feedback, musical pitch, and vowel color as three separate controls.

1. Listen first

Press Run to sustain a YM2612 tone at 130 Hz. In experiment A, the pitch stays fixed while the filter moves through a → i → u → e → o. The electronic voice color comes from the combination of chip harmonics and software resonances.

Run starts playback; Stop stops it. Edit the code during playback and press Run again to apply changes. The same-named FX keeps its filter state, and livePrepare avoids retriggering the sustained source. Stop and Run for a fresh start. Play only one embedded example at a time: independent Playgrounds can otherwise sound together.

Open this code in a separate Playground tab ↗

2. Start with the chip, then add the filter

YM2612 OP1 + feedback → harmonic-rich tone → three parallel formant filters → mix → output

The starting preset is FM_PRESETS["sine"]. This example selects algorithm 7, in which all four operators can be carriers, but enables only OP1. The other operators are muted. OP1 is useful here because the chip's feedback path belongs to that operator.

At feedback = 0, OP1 is close to a sine-wave source. Raising feedback bends the oscillator's waveform and supplies more harmonics for the filter to emphasize. Start with feedback = 6, then compare 0, 3, and 6. Feedback changes the chip's source tone; it does not move F1, F2, or F3.

operatorLevel is the YM2612 Total Level (TL), a raw chip attenuation value: smaller is louder, larger is quieter. It is not a percentage. The example uses TL 16 for OP1 and TL 127 for the muted operators. Change TL cautiously when comparing different feedback settings.

The formant filters are software processing in liveFx on the AudioWorklet thread, after the chip output. The YM2612 does not contain these three formant filters. This does not emulate an LPC speech chip or analyze a microphone signal.

The formants table contains [F1, F2, F3] in Hz for each vowel. Each band-pass receives the same input and the three outputs are mixed. F1 broadly relates to vowel openness, F2 to front/back tongue position, and F3 adds further voice quality. These are illustrative targets, not universal measurements. The formant vowels chapter explains the table and filter.

4. Compare experiments A, B, and C

experimentYM2612 pitchFormant filter
'A'Fixed at carrierHzMoves through five vowels
'B'Repeating frequency patternFixed at fixedVowel
'C'Same repeating frequency patternMoves through five vowels
  1. Start with A and mix: 0. Change feedback from 6 to 0 and Run again. This isolates what the YM2612 contributes.
  2. Restore feedback 6 and mix: 1. The filter now has more harmonics to shape. With feedback 0, the single main frequency cannot convincingly supply three vowel resonances.
  3. Set experiment = 'B' and fixedVowel = 0. The melody moves but the resonance targets stay fixed. Try fixedVowel 1 next.
  4. Try C, then slow the vowel cycle with vowelSeconds: 2.5. Source pitch and vowel motion are controlled separately.
  5. For the LFO experiment, choose B and set lfoHz: 0.8, lfoDepth: 0.3. The filter moves periodically while the source loop continues to control pitch.

The source loop calls fm.setFrequency. The formant processor changes resonance frequencies using its own audio-thread position. Changing BPM does not change these second-based controls. A higher fundamental has fewer harmonics inside the formant regions, so the perceived vowel can still vary with source pitch.

5. Compare the chip and filtered sound in FX Monitor

After Run, open FX Monitor and select formant-ym2612. Blue is input from the sound sources; orange is the filtered output. Use View → Spectrum to compare harmonic balance and Oscilloscope to compare waveforms. Keep Y fixed when comparing heights; input and output share the scale.

With mix 0, input and output should overlap. With feedback 6 and mix 1, the orange spectrum emphasizes regions near the formants. Actual peaks remain near the source harmonics rather than necessarily exactly at F1, F2, and F3. In A, watch the broad spectral shape move without changing harmonic spacing. In B, harmonic spacing changes while the resonance targets stay put.

The effect processes the mixed source audio, not a selected YM2612 operator or channel. Keep other sources quiet when learning from this comparison.

6. What is smoothed, and what is not?

The formant processor keeps separate filter histories for the left and right audio channels, calculates coefficients from the actual AudioWorklet sample rate, smooths parameter targets, and limits excessive wet output. The same processing is used in the earlier three formant chapters.

Raw chip edits are separate: abrupt feedback, TL, or pitch changes can create waveform discontinuities and click sounds. Smooth formant movement does not guarantee that a direct YM2612 register change is click-free. The example preserves the source key state when code is applied, but does not add automatic smoothing to the chip's parameters.

This is a synthetic voice-color experiment. It does not produce consonants, reconstruct a human vocal tract, or read text aloud. Listener, pitch, feedback, and playback device affect how clearly the vowels are heard. Start at a comfortable level.

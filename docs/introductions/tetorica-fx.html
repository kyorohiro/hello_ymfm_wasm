FX INTRODUCTION / WORK IN PROGRESS

Learn FX by listening and writing code

English | 日本語

Change loudness, chop sounds, and distort waveforms. Explore small PCM transformations, filters, and reverb through editable Playground examples.

This series is a work in progress. Drafts of all 15 chapters, from Gain to combining effects, are available. Their explanations and examples will be refined through listening.

Start here

  1. Gain: multiply the waveform — prototype
    Explore amplitude and loudness with the built-in Gain and multiplication in liveFx.
  2. Slicer: chop a sustained sound — prototype
    Change Gain periodically and carry the processing position forward in state.

Each article embeds an editable Playground. Run starts playback; Stop ends it. Edit code and Apply, then compare liveFx input and output in FX Monitor. Stop the previous Playground before comparing.

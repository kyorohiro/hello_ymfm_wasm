Combining FX: series, parallel, and processing order

English | 日本語

Combine the effects from earlier chapters and hear how order and mixing change the sound.

This article is a work in progress. The examples will be refined through listening. Run starts playback; Stop ends it. Use Apply after editing values. Stop the playing iframe before trying another one.

Series: change the processing order

Audio passes through the setChain array in order. Filter → Distortion removes high frequencies before creating harmonics. Distortion → Filter also removes some of the newly created harmonics. Change reverse and Apply to compare brightness.

Parallel: adjust dry and delayed sound separately

branch processes one path in series. parallel sends the same input to each path and adds their outputs, without averaging. With both gains at 1, overlapping copies of the same sound increase the amplitude.

This example mixes the dry signal at 0.5 with only the wet Delay signal at 0.5. Set dry to 0 for delayed sound alone, or wet to 0 for dry sound alone. Because feedback is present, these settings do not guarantee a limited peak.

Graphs and liveFx

Create FX nodes once with livePrepare; change settings or connections with Apply. Create separate nodes for each path rather than sharing one node between paths. Avoid repeatedly creating nodes inside liveLoop.

Here, liveFx("none") observes the signal after the built-in chain. Monitor input and output are identical; it does not show intermediate points in each branch. liveFx is a separate processing stage and cannot be inserted among built-in nodes in this example's setChain.

Series and parallel routing also change loudness. Match the final loudness when judging differences in processing order.

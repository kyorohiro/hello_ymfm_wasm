Software connection presets group SCSP slots into voices. Select A–F to edit on the same canvas. Apply before switching; unapplied drawings are discarded. Only Output operators reach the speakers. TL controls each operator's strength. Voice mode and Connection changes stop notes. All modulator ratios resets A to 1 and B–F to the chosen value.

Waveform drawing, voice allocation, repeated PCM guards and preset files are software features. Slot FM, envelopes and LFO run in the SCSP core. The fixed core has zero slot-write delay; hardware timing fidelity is not guaranteed. DSP editing and SSF playback are not exposed here.

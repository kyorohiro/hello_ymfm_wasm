SCSP DSP · Delay

Release a short note to hear the repeats. A sustained sine mainly changes level. Shared mono Delay runs inside the SCSP DSP. Send / Return: 0 = mute, 7 = maximum. Changing Time or Enable clears echoes. Stop clears the tail.

Choose an operator to edit on the single canvas below. Lines show modulation; Output operators feed the mixer and DSP Send. Apply drawings before switching. Unapplied drawings are discarded.

Waveform drawing, voice allocation, repeated PCM guards and preset files are software features. Slot FM, envelopes and LFO run in the SCSP core. The fixed core has zero slot-write delay; hardware timing fidelity is not guaranteed. The original mono Delay program uses 64 KiB of SCSP RAM, leaving 448 KiB for PCM and guards. Custom DSP programs, Reverb and SSF playback are not exposed here.

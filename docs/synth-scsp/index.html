Custom · operator A
?

Choose an operator above, then its inputs and direct output. An operator can both modulate another and produce sound. An ordinary single source feeds both hardware inputs; with two sources, SCSP averages X and Y. Clear an existing input before reversing a connection.

In Custom4/6, multiple OPs can independently feed themselves. Each Self uses X32/Y0 to average its own two sound-stack histories. Selecting Self for Input X replaces that OP's external inputs and reserves both taps; Input Y is disabled. Other OPs can receive and merge their outputs. Depth 0 turns off only that receiving OP's modulation in this Synth adapter. New Auto/Code notes initialize two owned history cells per Self OP; live Depth edits keep history. This initialization is Synth software.

This graph editor and its voice allocation are Synth software over SCSP slot modulation. Custom2 keeps its one-Self limit. Custom4/6 support independent Self OPs alongside acyclic external connections. A Self target cannot also receive another OP, and multi-OP cycles remain outside this editor. Raw physical CH controls keep their existing behavior.

Changing the operator count keeps routes between remaining operators. Added operators start disconnected with direct output off; removed operators and their routes are dropped. Entering Custom for the first time starts from the selected Chain / Pairs / Branch template.

Changing OP count keeps surviving Self connections; shrinking removes routes and outputs for removed OPs. If both A and B remain Self when selecting 2OP, the change is rejected and the current sound is kept; clear one Self input first. The zero-delay editor core's steady Self histories are one and two native 44.1 kHz samples old; full physical SCSP pipeline accuracy is not implied.

A graph change releases the current Auto notes; Code keeps running and its next notes use the new graph. Independent physical keyboard voices retain their owners. The graph is saved in custom instrument presets.

										the Synth DSP after validation. A changed program clears its wet
										tail while voices continue; failed Apply keeps the previous program.
										SSF playback owns a separate DSP program in the song engine.
									

									

										Save setup to Code writes the applied Synth DSP program, coefficients
										and effect settings to Files. It keeps your draft and current
										performance. Select the saved JavaScript and Run to restore that
										setup. PCM, notes, live DSP history and the separate SSF
										engine are not included.
									

									

										Loading an example stages source and its recommended coefficients.
										Check and Apply changes them together. Live coefficient edits remain
										independent; Reset draft keeps the live coefficients. Reload restores
										only source text, so load the example again to stage its coefficients.
									

									

										The FIR low-pass adds adjacent samples; the high-pass subtracts the
										previous sample using the same instructions and negative COEF1.
										Enable DSP return and use direct level 0 for wet-only comparison.
										Use Spectrum to compare low-frequency attenuation in high-pass and
										high-frequency attenuation in low-pass. A low sine changes little
										in low-pass. At a switch to FIR, the first frame can contain old TEMP
										history; its next frame uses the new input history.
									

									

										The 1-pole IIR stores the previous 24-bit internal output, then mixes
										COEF1 × previous output with COEF2 × current input. COEF0 and Time
										are unused. Recommended codes 3840 / 256 give stable decay and add
										to 4096 for approximately unity passband gain. Other raw values can
										change gain and sustain; no automatic tuning is performed. Old IIR
										history recurs across samples rather than disappearing after one frame.
										Clearing Delay RAM with Apply / Enable does not reset TEMP. Stop
										resets the history.
									

									

										This first profile keeps the existing packed 64 KiB ring, COEF0–2,
										MADRS0–1 for Delay; RAM-free programs can use MIXS0/1 and EFREG0/1. Check rejects unsupported controls.
										Each step sets controls in parallel; output and memory writes use
										the previous accumulator. RAM I/O runs on odd steps in this core.
									

									

										Copy and Save export the draft, including unapplied edits. Restored
										draft text is never applied automatically. Voice presets and Cassettes
										do not include this DSP source; save a .scspasm copy to keep it.

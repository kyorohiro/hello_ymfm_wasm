# Tetorica SCSP Synth

Serve this directory over HTTPS or localhost and open index.html. AudioWorklet needs a secure context. Upload the standalone ZIP as an itch.io HTML project with index.html as its entry.

Start audio, then play the screen keys or A W S E D F T G Y H U J K. Choose **PCM**, **2-operator FM**, **4-operator FM**, or **6-operator FM**. Six slots hold the A–F editing sources. Playback uses the other 26 slots: **26 PCM / 13 two-op / 6 four-op / 4 six-op voices**. Each key owns its complete group. Release, voice stealing and Stop affect every operator together; an old key release cannot stop its replacement. Mode and Connection changes stop existing notes after successful validation.

Choose **Chain** (all operators in series), **Pairs** (parallel two-op groups), or **Branch** (a tree with up to two inputs per slot). The connection summary shows every edge and the output operators. Only output operators reach the speakers; other operators feed the sound stack. These are software connection presets using the existing SCSP slot hardware, with no feedback or arbitrary graph editor.

Use **A–F** to change the editing target on the **same canvas**. Draw a shape or import a file, Apply PCM, then play a new note. Each operator has its own PCM, EG, LFO, mix and FM frequency ratio. Apply drafts before switching; unapplied drawings are discarded. Any operator receiving modulation needs a full forward loop (loop start 0). The software allocator adds repeated waveform guards for depths 0–12. Operators without an incoming FM edge can play one-shots. An invalid connection or mode change leaves the current instrument playing.

Change **FM depth**, **Selected operator ratio** or Pitch while holding a note. **All modulator ratios** resets A to 1 and B–F to the chosen value, then individual ratios can be adjusted again. Ratio settings affect FM modes; PCM plays A at the keyboard pitch. TL controls the selected operator's strength. Direct level and Pan affect only operators marked Output.

WAV and browser-supported codecs up to 64 MiB can be decoded. Choose a region, Use selection in waveform, then Apply PCM. Only a selection of 2–65,535 mono samples enters the 512 KiB SCSP RAM. Lower the selection rate for longer regions. Recorded root MIDI note is manual. A one-shot A remains valid in PCM mode; switching it to a connection that modulates A requires a full loop. Invalid edits and files leave the current instrument intact.

PCM and envelope changes affect new notes. Pitch, ratio, depth, mix and LFO also affect active voice groups, including release tails. Held/releasing notes keep their original PCM after an operator edit. Stop silences immediately and releases playback references for safe editor RAM reuse. At the voice limit, released groups are stolen first, then the oldest held group. Raw SCSP mixing can saturate at large sums.

Save preset stores **version 3 JSON**, including all six applied PCM waveforms, EG/LFO/mix, mode, connection, individual ratios, FM depth and pitch. Open preset validates the whole file before replacing the instrument, then stops voices and clears the old bank. Files are limited to 8 MiB. Old version 1 files load as PCM; version 2 files retain their PCM/two-op voice and receive default operators C–F. Unapplied drafts are not saved.

Drawing, conversion, repeated PCM guards, voice allocation and preset files are software features. Slot modulation, EG and LFO run in the SCSP core. The fixed core has zero slot-write delay; physical SCSP timing, low-depth behavior and address clipping are not hardware-fidelity guarantees. DSP editing, SSF playback and Native audio are not exposed by this standalone page.

All runtime dependencies are local. Navigation links open the full website. This archive contains no game, BIOS or recording. The main page and dedicated AudioWorklet are bundled separately.

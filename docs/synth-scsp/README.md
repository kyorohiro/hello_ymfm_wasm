# Tetorica SCSP Synth

Serve this directory over HTTPS or localhost and open index.html. AudioWorklet needs a secure context. Upload the standalone ZIP as an itch.io HTML project with index.html as its entry.

Start audio, then play the screen keys or A W S E D F T G Y H U J K. Choose **PCM** or **2-operator FM**. Two slots hold the Carrier / Modulator source settings; playback uses the remaining slots: **30 PCM voices or 15 FM voices**. Each FM key owns a complete Modulator → Carrier pair. Release, voice stealing and Stop affect both operators together; an old key release cannot stop its replacement. Mode changes stop existing notes.

Use **A · Carrier / B · Modulator** to change the editing target on the **same canvas**. Draw a shape or import a file, Apply PCM, then play a new note. Apply drafts before switching operators; unapplied drawings are discarded. In FM mode, the carrier must be a full forward loop (loop start 0). The software allocator adds repeated waveform guards for depths 0–12, so modulation reads remain inside that waveform. The modulator can use a different PCM format, waveform, loop and envelope. Its Direct level is fixed at 0; TL controls the modulation strength. Change **FM depth** and **Modulator ratio** while holding a note to change its timbre. Pitch transposes the whole pair. This first version has one fixed 2-operator connection; arbitrary algorithms and self feedback are later work.

WAV and browser-supported codecs up to 64 MiB can be decoded. Choose a region, Use selection in waveform, then Apply PCM. Only a selection of 2–65,535 mono samples enters the 512 KiB SCSP RAM. Lower the selection rate for longer regions. Recorded root MIDI note is manual. A one-shot carrier remains valid in PCM mode; switching it to FM is rejected until a full loop is applied. Invalid edits and files leave the current instrument intact.

PCM and envelope changes affect new notes. Pitch, ratio, depth, mix and LFO also affect active voice groups, including release tails. Held/releasing notes keep their original PCM after an operator edit. Stop silences immediately and releases playback references for safe editor RAM reuse. At the voice limit, released groups are stolen first, then the oldest held group. Raw SCSP mixing can saturate at large sums.

Save preset stores **version 2 JSON**, including both applied PCM waveforms, EG/LFO/mix, mode, FM depth, ratio and pitch. Open preset validates the whole file before replacing the instrument, then stops voices and clears the old bank. Files are limited to 4 MiB. Old version 1 files load as PCM voices with a default modulator. Unapplied drafts are not saved.

Drawing, conversion, repeated PCM guards, voice allocation and preset files are software features. Slot modulation, EG and LFO run in the SCSP core. The fixed core has zero slot-write delay; physical SCSP timing, low-depth behavior and address clipping are not hardware-fidelity guarantees. DSP editing, SSF playback and Native audio are not exposed by this standalone page.

All runtime dependencies are local. Navigation links open the full website. This archive contains no game, BIOS or recording. The main page and dedicated AudioWorklet are bundled separately.

# Tetorica SCSP Synth

Serve this directory over HTTPS or localhost and open index.html. AudioWorklet requires a secure context; opening files directly is unsupported. Upload the ZIP as an itch.io HTML project with index.html as its entry.

Start audio, then play the screen keys or A W S E D F T G Y H U J K. Slot 1 is the source editor, and 31 other slots provide keyboard polyphony. Select a shape or draw on the single canvas, then Apply PCM and play a new note. For an audio file, choose a region, Use selection in waveform, then Apply PCM. WAV and browser-supported codecs up to 64 MiB can be decoded; only a selection of 2–65,535 mono samples enters the 512 KiB SCSP RAM. Lower the selection sample rate for longer regions. Recorded root MIDI note is manual. Drawing, conversion and preset files are software features.

Envelope and PCM changes affect new notes. Pitch and mix also affect held keyboard notes. Ordinary key release preserves the envelope and sample memory; Stop silences immediately and releases playback references for safe editor RAM reuse. Raw SCSP mixing can saturate at large sums. Save preset stores the applied PCM and voice settings, not an unapplied draft; Open preset restores it. Presets use version 1 JSON, limited to 2 MiB. LFO, slot FM, DSP editing, SSF playback and Native audio are not exposed by this standalone page.

All runtime dependencies are local. Navigation links open the full website. This archive contains no game, BIOS or recording. The main page and AudioWorklet are bundled separately. The original Emscripten factory and WASM remain byte-identical under generated/. Original JavaScript inputs and their hashes are included in sources/scsp-synth-browser-inputs.zip and sources/scsp-synth-browser.json. SCSP/DSP C++ source, original MAME upstream, attribution, license and the standalone Emscripten rebuild recipe are under sources/; start with sources/SCSP.md. The fixed SDK includes its unpublished local-candidate status in sources/SCSP.json. See LICENSE and licenses/mame-scsp/LICENSE (BSD-3-Clause).

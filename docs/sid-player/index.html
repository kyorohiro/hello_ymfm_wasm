Supported files & source code

This first player runs ROM-independent PSID v2 tunes with explicit PAL / 6581 flags, one SID, VBI speed and init/play routines in RAM. It calls the tune's play routine once per PAL frame.

RSID, CIA / IRQ drivers, NTSC, 8580, multiple SIDs and ROM-dependent tunes are not supported yet. This is a bounded music driver host, with a 6502 CPU and the existing chips/m6581 approximation; it is not a complete C64 emulator. Runtime failures stop playback and explain the reason.

The demos are original test programs. No game music or C64 ROM dump is included. Voice extraction into the Synth is a later step.

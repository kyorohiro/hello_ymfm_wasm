Playback settings · PAL / 6581 & C64 ROMs

Both PSID and RSID use PAL / 6581. If a file leaves its clock or SID model unspecified, choose this target explicitly below, then press Apply / retry SID.

Files explicitly requiring NTSC, 8580 or multiple SIDs remain unsupported.

PSID CIA subtunes and RSID run the C64 CPU, CIA timers and VIC interrupts continuously. The built-in IRQ environment supplies a limited, original boot shim. Tunes that need BASIC or other ROM routines require your own C64 firmware. These ROM settings apply to PSID CIA and RSID; PSID VBI uses its separate init/play host.

Select all three before applying. Exact size is checked; firmware compatibility is not guaranteed. These files stay in memory, are not uploaded or saved, and are not included in the player download.

Supported files & source code

PSID v2 selects its backend per subtune: VBI uses a ROM-independent init/play host, while CIA uses the C64 machine's Timer A interrupts. RSID v2 uses the same C64 machine with CPU, both CIAs, VIC, memory banking and the 6581 approximation. Both target PAL and one 6581.

The built-in C64 environment has limited original IRQ / NMI firmware; unsupported ROM access stops with a reason. BASIC and ROM-dependent programs need your supplied Character, BASIC and KERNAL ROMs. NTSC, 8580 and multiple SIDs remain unsupported. Machine and SID timing have known approximation limits; this is not a claim of complete hardware accuracy.

Volume-DAC / digi playback through $D418 is not modeled by this SID core. Such programs can execute correctly but remain silent. Supplied-ROM startup has synthetic tests; compatibility with real BASIC / KERNAL firmware still needs separate confirmation.

The demos are original test programs. No game music or C64 ROM dump is included. Voice extraction into the Synth is a later step.

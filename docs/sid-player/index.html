Playback settings · PAL / SID model & C64 ROMs

Auto uses the file's 6581 or 8580 declaration. For an unknown or either model, choose 6581 / 8580 above or use the default below. Changing SID model checks the latest file again; press Play after a successful selection.

Uncheck to require a declared PAL clock and a declared or manually selected model. Known model declarations are preserved: a conflicting model choice is rejected. Press Apply / retry SID after changing these settings.

8580 is a Preview model. Files requiring NTSC or multiple SIDs remain unsupported.

C64 machine uses hardware raster interrupts and supports longer initialization. Direct VBI is available for 6581 comparison and tunes without free driver RAM; 8580 VBI requires C64 machine. Press Apply / retry SID after changing settings.

C64 VBI, CIA subtunes and RSID run the C64 CPU, CIA timers and VIC interrupts continuously. The built-in IRQ environment supplies a limited, original boot shim. Tunes that need BASIC or other ROM routines require your own C64 firmware. ROM settings apply to these machine backends. Direct VBI uses its separate init/play host.

Supported files & source code

PSID v2 uses the C64 machine by default: VBI play calls follow VIC raster interrupts, and CIA play calls follow Timer A interrupts. RSID v2 uses the machine for its own interrupt or continuous code. Auto follows the declared 6581 / 8580 model; 8580 is a Preview. Direct VBI remains available for 6581 comparison. All target PAL and one SID.

PSID relocation fields describe free RAM for the player driver; the tune stays at its original load address. C64 VBI and CIA require a free, always-visible driver page. Direct VBI can also try no-free-page headers. C64 VBI streams initialization with a two-million-cycle limit; unsupported expansion devices still stop with a reason.

The built-in C64 environment has limited original IRQ / NMI firmware; unsupported ROM access stops with a reason. BASIC and ROM-dependent programs need your supplied Character, BASIC and KERNAL ROMs. NTSC and multiple SIDs remain unsupported. Machine and SID timing have known approximation limits; this is not a claim of complete hardware accuracy.

Volume-DAC / digi playback through $D418 is not modeled by the 6581 core, and accurate DAC/digi behavior in 8580 remains a research item. Programs can execute correctly while some sampled parts remain silent. Supplied-ROM startup has synthetic tests; compatibility with real BASIC / KERNAL firmware still needs separate confirmation.

The demos are original test programs. No game music or C64 ROM dump is included. Voice snapshots capture a moment of register settings; they do not reconstruct the tune's software instrument automation.
